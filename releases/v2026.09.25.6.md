이전 공개 릴리즈 **v2026.09.25.5** 이후 변경 사항입니다.

- **사용량 수집:** 독립 백그라운드 수집기가 기록을 읽고 GUI와 캐시 작업기에 결과를 전달합니다. 화면을 다시 열거나 작업기가 함께 실행될 때 수집이 중복되는 문제를 줄였습니다.
- **수집 경로 정리:** 이전 직접 수집기와 작업기 색인 호환 경로를 제거했습니다. GUI와 캐시 작업기는 같은 수집 결과를 받아 사용합니다.
- **제거 처리:** 앱 제거 시 독립 수집기의 종료와 예약 작업 정리를 추가했습니다. 사용 중인 연결은 강제로 종료하지 않습니다.
- **수집기 안정성:** 여러 Codex 홈의 순서와 관측 범위를 보완했습니다. 일회성 진단은 직접 시작한 수집기를 종료하며, 작업 스케줄러의 시간 초과는 재시도 가능한 지연으로 표시합니다.
- **문서:** 한국어·영어 README에 캐시 관리의 동작, 활성화 조건과 사용량 표시를 추가했습니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 앱의 **설정 → 정보·문제 해결 → 업데이트 확인 및 설치**를 사용하세요.

This update unifies usage collection in a dedicated background service, removes retired collection paths, and documents cache management in both READMEs.
