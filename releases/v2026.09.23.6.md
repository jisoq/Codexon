# Codexon 2026.09.23.6

First public-ready Windows x64 release of **CODEX·ON**. The dashboard, tray, overlay, executable, and ZIP use the Codexon name and artwork. Korean and English UI are available from **Settings → General → Language**; a language change applies on the next launch. The dashboard now fits smaller usable screen areas, and proxy errors have expandable details.

Extract the entire `Codexon` folder. For an existing installation, close the old GUI before launching the new executable. If model monitoring is enabled, check the separate proxy version under **Settings → Proxy** and use its update control when offered. Keep the previous executable folder until the proxy update completes. See the [user guide](https://github.com/jisoq/Codexon/blob/main/docs/user-guide.md) for update, removal, and recovery.

The Windows ZIP is accompanied by a SHA-256 file and a matching Qt/PySide6 source asset. API-equivalent costs are estimates, not Codex billing amounts. The proxy switch can briefly reject new connections while existing requests finish.
