## [2026.10.16.1] - 2026-10-16

### Changed

- 구독 모니터링은 현재 주기부터 표시하고, 전체 합계와 이전 주기는 준비가 끝나면 제공합니다.
- 전체 차트는 주기별 요약값을 연결하며, 점을 선택하면 해당 주기의 상세 차트를 엽니다.
- 사용량 화면에서 필요한 기록을 먼저 조회하고, 화면 전환과 기록 갱신의 반복 계산을 줄였습니다.
- 새 기록 반영과 앱 재시작 시 기존 기록을 재사용하도록 개선했습니다.
- 기록 저장과 계정 조회의 불필요한 자원 사용을 줄였습니다.
- 변경 없는 동안의 반복 처리와 메모리 사용을 줄였습니다.

### Fixed

- 선택한 구독 주기의 기록 초기화와 상세 표시를 수정했습니다.
- 과거 기록이 수정되거나 수집이 중단된 뒤에도 변경 내용을 올바르게 반영하도록 수정했습니다.
- 토큰 사용량 근거가 충돌하는 기록의 비용 표시를 수정했습니다.
- 캐시 문제의 복구 판정에 최신 근거를 반영하도록 수정했습니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 **설정 → 앱 정보**에서 업데이트하세요. 인증 정보와 기존 사용량 기록은 유지합니다. 프록시를 꺼 둔 경우 그대로 유지합니다.

Qt/PySide6 6.11.2 소스는 기존 고정 다운로드 위치를 재사용합니다. 설치 프로그램에는 SHA-256 파일이 함께 제공됩니다.

### Changed

- Subscription monitoring shows the current cycle first, then makes overall totals and earlier cycles available when ready.
- Overall charts connect per-cycle summaries; selecting a point opens that cycle's detailed chart.
- Usage screens query the records they need first and perform less repeated calculation during navigation and updates.
- New-record processing and app restarts reuse existing records more effectively.
- Reduced unnecessary resource use during record storage and account queries.
- Reduced repeated processing and memory use while records remain unchanged.

### Fixed

- Fixed record reset and detail display for the selected subscription cycle.
- Fixed updates after historical records change or collection is interrupted.
- Fixed cost display for records with conflicting token-usage evidence.
- Fixed cache recovery assessment to use fresh evidence.

On Windows 10/11 x64, run **Codexon-Setup.exe** or update through **Settings → About**. Authentication and existing usage records are preserved. A disabled proxy remains disabled.

Qt/PySide6 6.11.2 sources reuse their existing locked download location. A SHA-256 file accompanies the installer.
