이전 공개 릴리즈 **v2026.09.30.1** 이후 변경 사항입니다.

- **캐시 관리 비활성화:** 캐시 관리 기능은 별도의 HTTP 연결을 통해 저렴한 비용으로 캐시를 유지할 수 있는 것을 확인했지만 모든 시도에 항상 성공하지는 않아 별도 방법을 찾기 전까진 비활성화됩니다
- **캐시 관리 정리:** 캐시 관리 화면과 설정, 추가 요청과 예약을 제거합니다. 구버전 캐시 작업기는 일반 관측 프록시로 전환합니다. 과거 사용량은 공통 기록에 보존하고 캐시 관리 전용 자료는 정리합니다. 일반 프록시, 모델명 비교, 캐시 적중률 분석과 알림은 계속 사용할 수 있습니다.
- **오버레이 배치:** 상세 오버레이 폭과 입력 및 출력 영역 배치를 조정했습니다. 선택 모드와 작업 상태에 맞춰 창 크기와 표시 항목을 갱신합니다.
- **구독 가치 환산:** Fast 요청은 Standard 기본 단가에 2.5배 사용량 배수를 적용합니다. 사용 한도와 비용 안내를 구독 가치 환산 기준으로 맞췄습니다. 표시 금액은 실제 구독 청구액이 아닙니다. [공식 사용량 배수](https://learn.chatgpt.com/docs/agent-configuration/speed)를 기준으로 합니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 앱의 **설정 → 앱 정보**에서 업데이트를 확인하세요. 업데이트 전 진행 중인 응답과 서버 호출을 마쳐 주세요. 기존 공통 데이터베이스나 `.codex` 폴더를 직접 삭제할 필요는 없습니다. 사용 방법은 [사용 안내](https://github.com/jisoq/Codexon/blob/v2026.10.01.1/docs/user-guide.ko.md)를 참고하세요.

Cache management is disabled until another method is found. Separate HTTP requests were observed to maintain cached context at low cost, but success was not consistent across attempts. The cache management page, settings, additional requests and schedules are removed. Existing cache workers migrate to the ordinary observation proxy. Historical usage remains in the shared records while cache-specific data is cleaned up. Proxy observation, model-name comparison, cache-hit analysis and alerts remain available.

This release also adjusts the detailed overlay layout and applies a 2.5 usage multiplier to Standard base rates for Fast subscription-value estimates. Displayed amounts are estimates, not subscription charges.

`Codexon-third-party-source-6.11.2.zip` contains the corresponding Qt/PySide6 sources and is not required to run the app. SHA-256 files accompany the downloads.
