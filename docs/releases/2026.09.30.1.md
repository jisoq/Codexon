이전 공개 릴리즈 **v2026.09.29.7** 이후 변경 사항입니다.

- **GPT-6.1 Sol 비용 계산:** `gpt-6.1-sol`의 Standard와 Fast 단가를 추가했습니다. 모델 단가 미확인으로 계산하지 못했던 호출 비용과 세션 합계를 표시합니다.
- **기존 기록 재계산:** 저장된 GPT-6.1 Sol 기록에도 새 단가를 적용합니다. 원본 토큰 수와 요청 모드는 유지합니다. 요청 모드나 필수 토큰 정보가 없는 기록은 기존처럼 비용 미확인 상태로 남습니다.

GPT-6.1 Sol 단가는 다음과 같습니다. 단위는 **100만 토큰당 USD**입니다.

| 구분 | Standard | Fast |
| --- | ---: | ---: |
| 입력 | $2.00 | $4.00 |
| 캐시 읽기 | $0.10 | $0.20 |
| 캐시 쓰기 | $2.50 | $5.00 |
| 출력 | $10.00 | $20.00 |

2026-09-30 확인한 [OpenAI 공식 단가](https://developers.openai.com/api/docs/models/gpt-6.1-sol)를 기준으로 합니다. 표시 금액은 API 단가 환산 추정액이며, Codex 구독 청구액이 아닙니다.
