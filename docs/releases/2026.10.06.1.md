이전 공개 릴리즈 **v2026.10.05.2** 이후 변경 사항입니다.

- **성능 추이 기간 탐색:** 최근 7일, 최근 30일 또는 시작일과 종료일을 지정해 조회할 수 있습니다. 그래프 아래 시간 탐색 막대로 구간을 이동하거나 범위를 조절할 수 있습니다. 최신 따라가기를 켜면 새 수집 자료에 맞춰 조회 구간이 이동합니다.
- **추론 수준 비교:** 평균 추론 토큰을 추론 수준별 탭으로 전환해 볼 수 있습니다. 같은 조회 기간의 탭은 공통 Y축을 사용하므로 수준별 차이를 같은 눈금에서 비교할 수 있습니다. 모델 범례는 옆 패널에서 확인하거나 숨길 수 있습니다.
- **남은 한도와 크레딧 확인:** 5시간과 주간 한도를 행별로 표시하고, 크레딧 잔액과 사용 초기화권을 별도 카드로 구분합니다. 제공된 초기화권의 지급 시각, 만료 시각과 상태를 현지 시간으로 확인할 수 있습니다. 크레딧 만료일이 제공되지 않으면 그 상태를 표시합니다.
- **의존성 보안 업데이트:** 네트워크 처리에 사용하는 `multidict`를 알려진 취약점의 수정 버전인 `6.9.1`로 갱신했습니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 앱의 **설정 → 앱 정보**에서 업데이트를 확인하세요. 업데이트 전 진행 중인 응답과 서버 호출을 마쳐 주세요. 기존 공통 데이터베이스나 `.codex` 폴더를 직접 삭제할 필요는 없습니다. 사용 방법은 [사용 안내](https://github.com/jisoq/Codexon/blob/v2026.10.06.1/docs/user-guide.ko.md)를 참고하세요.

Performance trends now offer the last 7 days, the last 30 days and custom date ranges. Use the timeline below the charts to move or resize the selected interval. Follow latest advances the interval as new collection data arrives.

Average reasoning tokens appear in tabs for each reasoning effort. Tabs share the same Y-axis for the selected period, making comparisons use a consistent scale. The model legend has a side panel that can be hidden.

Five-hour and weekly allowances appear in separate rows. Credit balance and usage reset credits have their own cards. Available reset-credit details show grant time, expiry time and status in local time. When credit expiry information is not provided, the app says so.

The bundled `multidict` dependency is updated to `6.9.1`, which fixes a known vulnerability.

`Codexon-third-party-source-6.11.2.zip` contains the corresponding Qt/PySide6 sources and is not required to run the app. SHA-256 files accompany the downloads.
