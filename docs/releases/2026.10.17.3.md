## [2026.10.17.3] - 2026-10-17

### Added

- 구독 모니터링에 주기별 소모량, 환산액, 실측 시간을 비교하는 표를 추가했습니다.
- 주기별 차트와 표의 강조 표시를 연결하고 표에서도 상세 차트를 열 수 있습니다.

### Changed

- 구독 모니터링의 요약 지표를 한 영역에 정리하고 주간 할당량 가치 기준선을 표시합니다.
- 성능 추이는 최근 7일을 기본으로 표시하고 선택한 모델과 모드에 맞춰 조회합니다.
- 성능 추이의 전체 기간은 선택한 모델의 출력 속도 기록에 맞춥니다.

### Fixed

- 성능 추이의 최근 기간과 최신 추적이 현재 시각을 기준으로 유지되도록 수정했습니다.
- 세션 전환 시 오버레이가 다시 로딩되거나 늦게 갱신되는 문제를 줄였습니다.
- 표의 강조 표시가 다른 셀로 이동하거나 화면을 닫은 뒤 남는 문제를 수정했습니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 **설정 → 앱 정보**에서 업데이트하세요. 인증 정보와 기존 사용량 기록은 유지합니다. 프록시를 꺼 둔 경우 그대로 유지합니다.

Qt/PySide6 6.11.2 소스는 기존 고정 다운로드 위치를 재사용합니다. 설치 프로그램에는 SHA-256 파일이 함께 제공됩니다.

### Added

- Added a cycle table comparing consumption, estimated value, and measured time in subscription monitoring.
- Linked chart and table highlights and added access to cycle details from table rows.

### Changed

- Grouped subscription summary metrics and added a weekly allowance value reference line.
- Performance trends now default to the last seven days and query the selected models and modes.
- The full performance range now follows output speed records for the selected models.

### Fixed

- Fixed recent performance windows and latest tracking to stay relative to the current time.
- Reduced overlay reloading and delayed updates when switching sessions.
- Fixed table highlights persisting after moving between cells or hiding the view.

On Windows 10/11 x64, run **Codexon-Setup.exe** or update through **Settings → About**. Authentication and existing usage records are preserved. A disabled proxy remains disabled.

Qt/PySide6 6.11.2 sources reuse their existing locked download location. A SHA-256 file accompanies the installer.
