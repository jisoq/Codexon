## [2026.10.20.2] - 2026-10-20

### Changed

- Codex 연결, 프록시 업데이트, 앱 종료의 진행 상태와 다음 동작을 일관되게 표시합니다.
- 앱 종료를 기다리는 동안 취소하거나 진행 중인 응답을 중단하고 종료할 수 있습니다.
- 릴리스 준비에서 중복 검증과 빌드를 줄이고 검증한 설치 파일을 재사용합니다.

### Fixed

- 프록시를 켠 뒤 이전 업데이트 실패가 계속 표시되는 문제를 수정했습니다.
- ChatGPT 종료와 Codexon 종료를 구분하고 진행 중인 응답과 기록을 마친 뒤 종료하도록 개선했습니다.
- 업데이트 도중 앱이 교체되거나 중단된 뒤 진행 상태를 복구하고 남은 업데이트를 이어갈 수 있습니다.
- 종료를 취소하거나 종료에 실패했을 때 앱을 계속 사용할 수 있도록 복구합니다.
- 연결 복구 중 다른 앱의 설정 변경을 덮어쓰거나 서비스를 중복 실행하는 문제를 방지했습니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 **설정 → 앱 정보**에서 업데이트하세요. 인증 정보와 기존 사용량 기록은 유지합니다. 프록시를 꺼 둔 경우 그대로 유지합니다.

Qt/PySide6 6.11.2 소스는 기존 고정 다운로드 위치를 재사용합니다. 설치 프로그램에는 SHA-256 파일이 함께 제공됩니다.

---

### Changed

- Made progress and next actions consistent across Codex connections, proxy updates, and app exit.
- Allow cancelling an exit while waiting, or interrupting active responses and exiting.
- Reduced duplicate verification and builds during release preparation and reuse verified installers.

### Fixed

- Fixed a previous update failure remaining visible after enabling the proxy.
- Distinguish ChatGPT exit from Codexon exit and finish active responses and records before shutting down.
- Recover update progress after app replacement or interruption and allow continuing the remaining update.
- Restore a usable app after cancelling an exit or when exit fails.
- Prevent connection recovery from overwriting another app's settings changes or starting duplicate services.

On Windows 10/11 x64, run **Codexon-Setup.exe** or update from **Settings → About**. Authentication and existing usage records are preserved. A disabled proxy remains disabled.

Qt/PySide6 6.11.2 sources reuse the existing fixed download location. A SHA-256 file accompanies the installer.
