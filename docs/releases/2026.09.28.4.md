이전 공개 릴리즈 **v2026.09.28.3** 이후 변경 사항입니다.

- **오버레이 상세 버튼 복원:** 헤더의 투명도 버튼 왼쪽에서 호출 상세를 열고 닫을 수 있습니다. 상세를 닫으면 버튼으로 키보드 포커스가 돌아옵니다.
- **최근 호출 고정과 해제:** 그래프를 클릭하면 선택한 호출의 선·수치·상세가 함께 고정됩니다. 같은 호출을 다시 클릭하면 해제되며, 최근 12개 범위를 벗어난 호출은 자동으로 고정이 풀립니다.
- **완료 구간 금액 누락 수정:** 화면에서 생략한 유휴 시간에 한도 경계가 관측되어도 완료 구간별 API 환산액을 유지합니다. 실제 관측이 부족하거나 진행 중인 구간은 계속 미확인으로 표시합니다.
- **영문 오버레이 표시 정리:** 호출 정보와 계산 설명, 시간·횟수 단위를 영문 설정에 맞게 표시합니다.
- **스케줄러 오류 구분:** 조회 실패를 작업 등록 실패로 표시하던 안내를 수정하고 실패 단계와 Windows 오류 코드를 함께 제공합니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 앱의 **설정 → 정보·문제 해결 → 업데이트 확인 및 설치**를 사용하세요. 업데이트 전 진행 중인 응답과 서버 호출을 마쳐 주세요. 기존 데이터베이스나 `.codex` 폴더를 삭제할 필요는 없습니다. 사용 방법은 [사용 안내](https://github.com/jisoq/Codexon/blob/v2026.09.28.4/docs/user-guide.ko.md)를 참고하세요.

This release restores the overlay detail button, fixes call pinning and unpinning, and preserves completed interval costs across hidden idle observations. It also improves English overlay text and Task Scheduler error diagnostics.
