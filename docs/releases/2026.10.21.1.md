## [2026.10.21.1] - 2026-10-21

- 알려진 제한: v2026.09.25.6에서 업데이트할 때 프록시 자동 교체가 간헐적으로 실패할 수 있습니다.

### Added

- 지표 비교에서 호출별 분포와 중앙값, 평균을 상자 그림으로 확인할 수 있습니다.

### Changed

- 지표 비교의 추론 토큰을 호출당 평균으로 표시하고 주요 지표 표에도 함께 보여줍니다.
- 오버레이에서 Codex 작업과 같은 에이전트 아이콘과 색상을 표시합니다.
- 하위 에이전트의 토큰 상세를 펼칠 때 오버레이 높이를 함께 조절합니다.
- 기록을 불러오는 동안 경과 시간과 진행 상태를 표시하고 Windows 애니메이션 설정을 반영합니다.

### Fixed

- 메인 창과 오버레이에서 기록 준비가 끝나지 않는 문제를 수정했습니다.
- 최대화한 메인 창을 다시 열 때 최대화 상태가 풀리는 문제를 수정했습니다.
- 기록 수집 중지나 조회 실패가 계속 로딩으로 표시되는 문제를 수정하고 다시 시도할 수 있도록 개선했습니다.
- 기록을 갱신하거나 상세를 열 때 기존 목록이 가려지거나 빈 행이 잘못 표시되는 문제를 수정했습니다.
- 비교 항목이 많을 때 메모리 사용을 줄이고 분포 계산의 정확성을 개선했습니다.
- 업데이트 재시도 중 이전 오류나 오래된 설치 안내가 남는 문제를 수정했습니다.
- 프록시 교체 중 늦게 도착한 상태가 진행 중인 업데이트를 되돌리는 문제를 방지했습니다.

### Security

- 네트워크 인증서 검증에 사용하는 보안 구성 요소를 업데이트했습니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 **설정 → 앱 정보**에서 업데이트하세요. 인증 정보와 기존 사용량 기록은 유지합니다. 프록시를 꺼 둔 경우 그대로 유지합니다.

Qt/PySide6 6.11.2 소스는 기존 고정 다운로드 위치를 재사용합니다. 설치 프로그램에는 SHA-256 파일이 함께 제공됩니다.

---

- Known limitation: Automatic proxy replacement can fail intermittently when updating from v2026.09.25.6.

### Added

- View per-call distributions, medians, and means as box plots in metric comparisons.

### Changed

- Show reasoning tokens as a per-call mean in comparisons and include them in the key metrics table.
- Show the same agent icons and colors as the corresponding Codex tasks in the overlay.
- Adjust overlay height when expanding subagent token details.
- Show elapsed time and progress while loading records and respect Windows animation settings.

### Fixed

- Fixed record preparation never completing in the main window and overlay.
- Fixed the main window losing its maximized state when reopened.
- Fixed stopped collection or failed queries remaining in a loading state and improved retry controls.
- Fixed existing lists being obscured or empty rows appearing incorrectly when refreshing records or opening details.
- Reduced memory usage with many comparison entries and improved distribution calculation accuracy.
- Fixed previous errors or outdated installation prompts remaining visible during update retries.
- Prevent late proxy status updates from reverting an update already in progress.

### Security

- Updated the security component used for network certificate validation.

On Windows 10/11 x64, run **Codexon-Setup.exe** or update from **Settings → About**. Authentication and existing usage records are preserved. A disabled proxy remains disabled.

Qt/PySide6 6.11.2 sources reuse the existing fixed download location. A SHA-256 file accompanies the installer.
