## [2026.10.20.1] - 2026-10-20

### Added

- 지표 비교에서 미확인 항목을 숨기거나 표시하는 버튼을 추가했으며 기본으로 숨깁니다.
- 오버레이 설정에서 차트 표시 방식과 한 번에 표시할 하위 에이전트 개수를 선택할 수 있습니다.

### Changed

- 다양한 성능 병목과 반복 처리의 비효율을 개선해 CPU, 메모리, 디스크의 불필요한 사용을 줄였습니다.
- 장시간 실행하거나 여러 하위 에이전트를 함께 사용할 때 화면 조작과 갱신 응답성을 개선했습니다.
- 지표 비교에서 모델과 추론 강도를 함께 표시하고 프로젝트, 요청 모드, 입력 규모, 캐시 활용 구간별로 비교할 수 있습니다.
- 비교 차트와 주요 지표 표를 전환하고 호출당 환산액, 응답시간, 입력 및 출력 토큰을 확인할 수 있습니다.
- 오버레이를 세로로 배치하고 Main Agent 아래의 Sub Agents 목록만 스크롤하도록 바꿨습니다.
- 하위 에이전트 표시 개수에 맞춰 오버레이 높이를 조절하고 대화별 설정을 유지합니다.
- Codex 색상 설정을 바탕으로 에이전트마다 일관된 색상을 표시합니다.
- 토큰 상세에서 입력과 출력의 수량, 비용, 산정된 호출 수를 함께 표시합니다.
- README의 한국어와 영어 이미지를 하위 에이전트가 있는 최신 오버레이로 교체했습니다.

### Removed

- 캐시 적중률 차트를 없애고 선택한 호출 비용 옆에 비율을 표시합니다.

### Fixed

- 사용량이 추가될 때 관계없는 화면까지 반복해서 갱신하거나 오버레이가 갱신 중 상태에 오래 머무르는 문제를 수정했습니다.
- 분석 결과 전달이 멈추거나 세션이 많을 때 분석기가 종료되어 기록 준비 상태가 지속되는 문제를 수정했습니다.
- 기록 조회와 구독 설정 변경 중 불필요한 재계산과 대기로 응답이 늦어지는 문제를 수정했습니다.
- 뒤늦게 도착한 설정을 같은 턴의 기존 호출에 반영하고 근거가 남아 있는 미확인 기록을 보정합니다.
- 높은 화면 배율에서 공간이 남아도 오버레이가 최소화되거나 설정 팝업이 잘리는 문제를 수정했습니다.
- 호출 기록 화면을 열 때 분석 요청이 실패하는 문제를 수정했습니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 **설정 → 앱 정보**에서 업데이트하세요. 인증 정보와 기존 사용량 기록은 유지합니다. 프록시를 꺼 둔 경우 그대로 유지합니다.

Qt/PySide6 6.11.2 소스는 기존 고정 다운로드 위치를 재사용합니다. 설치 프로그램에는 SHA-256 파일이 함께 제공됩니다.

### Added

- Added a Show unknown button to metric comparisons; unknown entries are hidden by default.
- Added controls for chart style and the number of visible subagents to overlay settings.

### Changed

- Addressed performance bottlenecks and repeated work to reduce unnecessary CPU, memory, and disk usage.
- Improved interaction and refresh responsiveness during long sessions and work with multiple subagents.
- Compare model and reasoning effort together, grouped by project, request mode, input size, or cache utilization.
- Switch between comparison charts and key metrics, including value, response time, and input and output tokens per call.
- Arranged the overlay vertically, with only the Sub Agents list scrolling below Main Agent.
- Fit overlay height to the visible subagent count and preserve each conversation's preference.
- Derived consistent agent colors from Codex appearance settings.
- Token details now show input and output quantities, costs, and the number of priced calls together.
- Replaced the Korean and English README images with the current overlay showing subagents.

### Removed

- Removed the cache hit rate chart and placed the percentage beside the selected call's cost.

### Fixed

- Fixed usage updates repeatedly refreshing unrelated views or leaving overlays in a refreshing state for too long.
- Fixed stalled analysis delivery and analysis stopping with many sessions, leaving records in a preparing state.
- Fixed unnecessary recalculation and waiting that delayed record queries and subscription setting changes.
- Apply late settings to existing calls in the same turn and correct unknown fields when retained evidence is available.
- Fixed overlays minimizing despite available space and settings popups being clipped at high display scaling.
- Fixed analysis requests failing when opening call history.

On Windows 10/11 x64, run **Codexon-Setup.exe** or update from **Settings → About**. Authentication and existing usage records are preserved. A disabled proxy remains disabled.

Qt/PySide6 6.11.2 sources reuse the existing fixed download location. A SHA-256 file accompanies the installer.
