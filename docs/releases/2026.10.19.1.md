## [2026.10.19.1] - 2026-10-19

### Added

- 오버레이 설정에서 차트 표시 방식과 높이를 조절할 수 있습니다.

### Changed

- 오버레이를 세로로 배치하고 Main Agent 아래의 Sub Agents 목록만 스크롤하도록 바꿨습니다.
- Codex 색상 설정을 바탕으로 에이전트마다 일관된 색상을 표시합니다.
- 토큰 상세에서 입력과 출력의 수량, 비용, 산정된 호출 수를 함께 표시합니다.

### Removed

- 캐시 적중률 차트를 없애고 선택한 호출 비용 옆에 비율을 표시합니다.

### Fixed

- 분석 결과 전달이 멈춰 수집과 분석 지연 표시가 계속되는 문제를 수정했습니다.
- 높은 화면 배율에서 공간이 남아도 오버레이가 최소화되는 문제를 수정했습니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하세요. 인증 정보와 기존 사용량 기록은 유지합니다. 프록시를 꺼 둔 경우 그대로 유지합니다.

설치 프로그램에는 SHA-256 파일이 함께 제공됩니다.

### Added

- Added chart style and height controls to overlay settings.

- Fixed analysis delivery stalling and leaving collection and analysis delay indicators active.
- Fixed the overlay minimizing despite available space at high display scaling.
