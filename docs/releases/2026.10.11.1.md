## [2026.10.11.1] - 2026-10-11

### Added

- **세션 시간순 차트:** 세션 기록에서 시간에 따른 사용량을 확인할 수 있습니다.

  **Session timeline:** Session history can show usage over time.

- **사용한도 구간 제외:** 선택한 구간을 집계에서 제외하고, 제외 관리 창에서 복원할 수 있습니다.

  **Quota interval exclusions:** Exclude selected intervals from aggregation and restore them through the exclusion manager.

### Changed

- **사용한도 화면:** 잔여량과 초기화 정보를 사이드바에 표시합니다. 주기 차트와 상세 정보 배치를 개선했습니다. 누적 예상 가치는 주간 예상 가치 아래에 표시합니다.

  **Quota presentation:** Remaining allowance and reset information appear in the sidebar. Cycle charts and details have improved layouts. Cumulative estimated value appears below weekly estimated value.

- **집계 처리:** 일부 CPU 집계를 Rust로 처리하고, 사용한도 계산을 별도 프로세스로 분리했습니다.

  **Aggregation:** Selected CPU aggregation work uses Rust, and quota calculations run in a separate process.

### Fixed

- **프록시 교체 대기:** HTTP 연결 정리 중 취소되어도 활성 연결 등록을 제거합니다. 이미 끝난 요청 때문에 업데이트가 계속 기다리는 문제를 수정했습니다. 기존 구버전에 이미 남은 상태는 정상 교체만으로 해소되지 않을 수 있습니다.

  **Proxy update waiting:** Active relay registration is removed even when HTTP cleanup is cancelled. Finished requests no longer leave updates waiting indefinitely. An already affected older process may still require recovery before replacement.

- **차트 선택 유지:** 사용량이 갱신될 때 차트 선택과 상호작용 상태를 유지하도록 개선했습니다.

  **Chart selection:** Usage refreshes preserve chart selection and interaction state.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 **설정 → 앱 정보**에서 업데이트하세요. 인증 정보와 기존 사용량 기록은 유지합니다. 프록시를 꺼 둔 경우 그대로 유지합니다.

On Windows 10/11 x64, run **Codexon-Setup.exe** or update through **Settings → About**. Authentication and existing usage records are preserved. A disabled proxy remains disabled.
