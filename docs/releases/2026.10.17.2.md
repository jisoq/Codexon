## [2026.10.17.2] - 2026-10-17

### Changed

- 구독 모니터링을 기본 화면으로 설정하고 주요 메뉴를 구독 모니터링, 지표 비교, 성능 추이로 정리했습니다.
- 로딩 막대가 실제 작업 단계에 따라 채워지도록 변경했습니다.
- 기존 결과를 갱신할 때 상단의 작은 새로고침 아이콘으로 상태를 표시합니다.
- 지표 비교의 페이지를 가상 스크롤로 바꾸고 모델 제목과 항목을 연속으로 표시합니다.
- 지표 비교에서 집계를 재사용하고 스크롤과 창 크기 변경에 따른 재조회를 제거했습니다.
- 구독 모니터링과 성능 추이의 차트 눈금을 읽기 쉽게 정리했습니다.

### Removed

- Home 요약과 화면 미리보기를 제거했습니다.

### Fixed

- 로딩 안내가 기존 차트와 겹치는 문제를 수정했습니다.
- 성능 추이의 조회 지연과 오버레이 갱신 중 결과가 비는 문제를 수정했습니다.
- 분석 중 기록 수집이 지연되는 문제를 줄이고 손상된 분석 캐시를 자동 복구합니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 **설정 → 앱 정보**에서 업데이트하세요. 인증 정보와 기존 사용량 기록은 유지합니다. 프록시를 꺼 둔 경우 그대로 유지합니다.

Qt/PySide6 6.11.2 소스는 기존 고정 다운로드 위치를 재사용합니다. 설치 프로그램에는 SHA-256 파일이 함께 제공됩니다.

### Changed

- Subscription monitoring is now the default screen, with main navigation focused on monitoring, metric comparison, and performance trends.
- Loading bars now fill according to actual processing stages.
- A small refresh icon in the header indicates updates while existing results remain visible.
- Replaced metric comparison pages with virtual scrolling that keeps model headings and items in sequence.
- Metric comparison reuses aggregates without querying again on scrolling or window resizing.
- Improved chart scale readability in subscription monitoring and performance trends.

### Removed

- Removed the Home summary and screen previews.

### Fixed

- Fixed loading indicators overlapping existing charts.
- Fixed slow performance queries and disappearing results during overlay refreshes.
- Reduced collection delays during analysis and added automatic recovery of corrupt analysis caches.

On Windows 10/11 x64, run **Codexon-Setup.exe** or update through **Settings → About**. Authentication and existing usage records are preserved. A disabled proxy remains disabled.

Qt/PySide6 6.11.2 sources reuse their existing locked download location. A SHA-256 file accompanies the installer.
