이전 공개 릴리즈 **v2026.09.28.4** 이후 변경 사항입니다.

- **설정 분류와 검색:** 설정을 일반, 화면 표시, 알림, Codex 연동, 문제 해결, 앱 정보로 묶었습니다. 한국어와 영어 검색으로 항목을 찾고 해당 위치로 바로 이동할 수 있습니다. 기존 설정값은 유지됩니다.
- **읽기 편한 설정 화면:** 넓은 창에서도 검색창과 설정 영역이 과도하게 늘어나지 않습니다. 소제목 사이에만 구분선을 표시하고, 설명에는 기능 동작과 적용 조건을 담았습니다.
- **작업표시줄 위젯 위치 조절:** 마우스로 위젯을 끌어 작업표시줄 안에서 위치를 바꿀 수 있습니다. 설정 화면에서도 이 조작을 안내합니다.
- **캐시 갱신 상태 확인:** 캐시 화면의 실행 상태와 추가 요청 비용을 정리하고, 설정에서 캐시 작업 화면으로 이동할 수 있습니다.
- **업데이트와 연결 복구:** 앱과 프록시 상태를 구분해 확인하고 필요한 업데이트를 선택할 수 있습니다. 연결 복구와 진단은 문제 해결에서 찾을 수 있습니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 앱의 **설정 → 앱 정보**에서 업데이트를 확인하세요. 이전 설정 화면에서는 **설정 → 정보 및 문제 해결**에서 업데이트를 확인할 수 있습니다. 업데이트 전 진행 중인 응답과 서버 호출을 마쳐 주세요. 기존 데이터베이스나 `.codex` 폴더를 삭제할 필요는 없습니다. 사용 방법은 [사용 안내](https://github.com/jisoq/Codexon/blob/v2026.09.29.4/docs/user-guide.ko.md)를 참고하세요.

This release organizes settings into six categories, adds bilingual settings search, and keeps controls within a readable width. It also adds taskbar widget dragging, clarifies cache activity, and separates update status from connection recovery.

`Codexon-third-party-source-6.11.2.zip` contains the corresponding Qt/PySide6 sources and is not required to run the app. SHA-256 files accompany the downloads.
