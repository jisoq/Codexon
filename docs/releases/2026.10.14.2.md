## [2026.10.14.2] - 2026-10-14

### Added

- 구독 모니터링에서 현재 주기의 측정 기록을 초기화하고 다시 측정할 수 있습니다. 이전 주기 기록은 유지합니다.

### Changed

- 주기별 차트 범례에 해당 주기의 평균 예상 가치와 최신 잔여량, 누적 측정 환산액을 표시합니다.
- 주기별 차트 주석에 전체 누적 예상 가치 대신 해당 주기의 평균 예상 가치를 표시합니다.
- 화면을 처음 열 때의 로딩과 스크롤 이동을 개선했습니다.
- 구독 모니터링을 일시정지해도 사이드바의 현재 잔여량은 계속 갱신합니다.
- 10억 이상 토큰 수를 B 단위로 표시합니다.

### Fixed

- 원격 세션에서 오버레이를 아이콘으로 표시합니다.
- 사용량 화면의 도움말 표시 오류를 수정했습니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 **설정 → 앱 정보**에서 업데이트하세요. 인증 정보와 기존 사용량 기록은 유지합니다. 프록시를 꺼 둔 경우 그대로 유지합니다.

Qt/PySide6 6.11.2 소스는 기존 고정 다운로드 위치를 재사용합니다. 설치 프로그램에는 SHA-256 파일이 함께 제공됩니다.

---

### Added

- Subscription monitoring can clear the current cycle's measurements and start measuring again. Previous cycles are preserved.

### Changed

- Per-cycle chart legends show the cycle's average estimated value, latest remaining allowance, and cumulative measured value.
- Per-cycle chart annotations show the cycle's average estimated value instead of the estimate across all cycles.
- Improved loading and scroll navigation when opening screens for the first time.
- The sidebar continues updating the current remaining allowance while subscription monitoring is paused.
- Token counts of one billion or more use the B suffix.

### Fixed

- Remote sessions display the overlay as an icon.
- Fixed help text display in the usage screen.

On Windows 10/11 x64, run **Codexon-Setup.exe** or update through **Settings → About**. Authentication and existing usage records are preserved. A disabled proxy remains disabled.

Qt/PySide6 6.11.2 sources reuse their existing locked download location. A SHA-256 file accompanies the installer.
