## [2026.10.18.1] - 2026-10-18

### Added

- 하위 에이전트별 또는 모델별 환산액과 토큰 구성을 확인하는 Sub 상세를 추가했습니다.
- 기록을 읽는 동안 오버레이에 로딩 애니메이션을 표시합니다.

### Changed

- 오버레이 호출 상세를 Sub 상세로 교체하고, 하위 에이전트가 있을 때만 상세 버튼을 표시합니다.
- Main Agent와 Sub Agent 환산액을 구분하고, 하위 에이전트의 표시 이름과 모델, 추론 수준, 모델 일치 여부를 보여줍니다.
- 오버레이는 환산액과 최근 호출을 기본으로 표시하고, Sub 상세는 에이전트별 보기를 기본으로 표시합니다.
- 오버레이 그래프에 영역 색을 채우고, 긴 이름은 한 줄로 줄여 표시합니다.
- 구독 모니터링 표에 주간 예상 가치를 표시하고, 주기 소모량과 실측 시간을 함께 비교합니다.
- 성능 추이에서 모델과 요청 모드를 구분하고 기록이 적은 구간도 확인하기 쉽게 표시합니다.

### Fixed

- 기록이 많은 세션에서 분석기가 중단되는 문제를 수정했습니다.
- 세션 전환 시 오버레이가 반복해서 로딩되거나 완료된 결과가 누락되는 문제를 줄였습니다.
- 구독 모니터링 표가 사용 가능한 공간보다 짧게 표시되는 문제를 수정했습니다.
- Sub 상세를 펼쳤을 때 모델명과 환산액이 중복되거나 클릭 테두리가 남는 문제를 수정했습니다.
- 영어 오버레이에서 하위 에이전트 개수가 잘못 번역되는 문제를 수정했습니다.
- 기록 변경과 업데이트 상태를 확인할 때 불필요한 반복 작업을 줄였습니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 **설정 → 앱 정보**에서 업데이트하세요. 인증 정보와 기존 사용량 기록은 유지합니다. 프록시를 꺼 둔 경우 그대로 유지합니다.

Qt/PySide6 6.11.2 소스는 기존 고정 다운로드 위치를 재사용합니다. 설치 프로그램에는 SHA-256 파일이 함께 제공됩니다.

### Added

- Added Sub details to inspect value and token composition by subagent or model.
- Added an overlay loading animation while reading session records.

### Changed

- Replaced overlay call details with Sub details, showing the details button only when subagents exist.
- Separated Main Agent and Sub Agent value and displayed each subagent's visible name, model, reasoning effort, and model match status.
- The overlay now defaults to value and recent calls, while Sub details defaults to grouping by agent.
- Filled the area under overlay graphs and kept long names on one truncated line.
- The subscription monitoring table now compares weekly estimated value, cycle usage, and measured time.
- Distinguished models and request modes in performance trends and improved visibility of sparse records.

### Fixed

- Fixed analyzer failures when processing sessions with extensive history.
- Reduced repeated overlay loading and lost completed results when switching sessions.
- Fixed the subscription monitoring table leaving available space unused.
- Removed duplicate model names and amounts from expanded Sub details and persistent click outlines.
- Corrected the subagent count translation in the English overlay.
- Reduced unnecessary repeated work when checking record changes and update status.

On Windows 10/11 x64, run **Codexon-Setup.exe** or update through **Settings → About**. Authentication and existing usage records are preserved. A disabled proxy remains disabled.

Qt/PySide6 6.11.2 sources reuse their existing locked download location. A SHA-256 file accompanies the installer.
