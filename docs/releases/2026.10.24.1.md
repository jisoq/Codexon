## [2026.10.24.1] - 2026-10-24

### Added

- 모델 불일치 기록을 보존하고 이후 정정 여부와 근거를 확인할 수 있습니다.
- 불일치 기록에서 요청과 응답의 추론 강도, 요청 모드, 사용량과 관측 근거를 확인할 수 있습니다.
- 오버레이 행 강조를 잔광 리본, 라이트 스캔, 테두리 스윕, 소프트 펄스, 신호 트레일 중에서 선택할 수 있습니다.
- 행 강조 방식을 바꿀 때 서로 다른 색으로 미리보기를 3회 자동 재생합니다.
- 연결 복구 도구에서 설정 파일 경로를 확인하고 연결 상태를 다시 검사할 수 있습니다.

### Changed

- 오버레이에서 불일치한 응답 모델을 먼저 표시하고 요청 모델에 취소선을 표시합니다.
- 내용이 바뀐 오버레이 행을 강조하고 Windows 애니메이션 설정을 반영합니다.
- 차트 표시 방식과 행 강조 설정을 오버레이 설정으로 옮기고 설정창을 작게 정리했습니다.
- 행 강조 애니메이션을 더 오래, 선명하게 표시합니다.
- 설치와 업데이트 전에 ChatGPT 종료와 자동 재실행을 안내하고 진행 여부를 확인합니다.
- 연결 복구 도구에서 긴 진단 내용을 읽고 복사할 수 있으며 진행 상태와 복원 완료, 정리 재시도를 구분합니다.

### Removed

- 세션 기록 화면의 타임라인과 호출 상세, 연결된 기록 이동 기능을 제거했습니다.
- 수집과 분석의 준비, 지연, 오류 상태에 따라 오버레이 본문을 자동으로 흐리게 표시하던 동작을 제거했습니다.

### Fixed

- 사용량 갱신이나 로그 기록 중 오버레이가 깜빡이거나 잠시 사라지는 문제를 수정했습니다. ([#15](https://github.com/jisoq/Codexon/pull/15))
- 백그라운드 갱신 중 펼친 상세 내용이 다시 그려지거나 활동 표시가 불필요하게 켜지는 문제를 수정했습니다. ([#19](https://github.com/jisoq/Codexon/pull/19))
- 시작 검사에 시간이 걸리면 사용량 분석이 실패하는 문제를 수정했습니다. ([#20](https://github.com/jisoq/Codexon/pull/20))
- 기록을 정상적으로 수집해도 수집 시작이나 지연 상태로 표시되는 문제를 수정했습니다. ([#20](https://github.com/jisoq/Codexon/pull/20), [#22](https://github.com/jisoq/Codexon/pull/22))
- 일부 설정 경로나 로컬 주소 충돌로 직접 연결 복원이 실패하는 문제를 수정했습니다. ([#21](https://github.com/jisoq/Codexon/pull/21))
- 업데이트 후 Codexon이 다시 열리지 않거나 연결 준비 전에 ChatGPT가 재실행되는 문제를 수정했습니다. ([#22](https://github.com/jisoq/Codexon/pull/22))
- 중단된 업데이트를 다시 시도할 때 종료 확인과 재실행을 잘못 처리하는 문제를 수정했습니다. ([#22](https://github.com/jisoq/Codexon/pull/22))
- 일시적인 파일 접근 오류로 업데이트 진행 상태를 읽지 못하는 문제를 수정했습니다. ([#22](https://github.com/jisoq/Codexon/pull/22))
- ChatGPT 창을 닫은 뒤 남은 백그라운드 프로세스 때문에 업데이트가 완료되지 않는 문제를 수정했습니다. ([#24](https://github.com/jisoq/Codexon/pull/24))
- 행 강조 방식을 고를 때 오버레이 설정창이 닫히는 문제를 수정했습니다. ([1d5c3c8](https://github.com/jisoq/Codexon/commit/1d5c3c8fa079e67fde17b93bc96faff7a8c85ff1))

### Security

- Windows에서 Python 패키지를 설치할 때 대상 폴더 밖에 파일을 만들 수 있는 취약점을 수정했습니다. ([GHSA-xmj3-9gf7-h52w](https://github.com/pypa/setuptools/security/advisories/GHSA-xmj3-9gf7-h52w))

**업데이트 안내**

- 업데이트 후 첫 실행에서 기존 사용량과 불일치 기록을 유지하며 사용량 분석을 다시 준비합니다.
- 기존 설치를 교체하기 전에 진행 중인 작업을 마치고 저장한 뒤 재시작 안내를 확인하세요.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 **설정 → 앱 정보**에서 업데이트하세요. 인증 정보와 기존 사용량 기록은 유지합니다. 프록시를 꺼 둔 경우 그대로 유지합니다.

Qt/PySide6 6.11.2 소스는 기존 고정 다운로드 위치를 재사용합니다. 설치 프로그램에는 SHA-256 파일이 함께 제공됩니다.

### Added

- Preserve model mismatch records and show later corrections with their supporting evidence.
- Inspect request and response reasoning effort, request modes, usage, and observation evidence in mismatch records.
- Choose Afterglow ribbon, Light scan, Edge sweep, Soft pulse, or Signal trail for overlay row highlights.
- Automatically preview each highlight choice three times in different colors.
- View the configuration file path and recheck connection status in the recovery tool.

### Changed

- Show a mismatched response model first in the overlay and strike through the requested model.
- Highlight overlay rows when their contents change and respect Windows animation settings.
- Move chart style and row highlight choices into a smaller overlay settings window.
- Make row highlight animations last longer and appear clearer.
- Request confirmation before installation or updates and explain that ChatGPT closes and reopens afterward.
- Make long recovery diagnostics readable and selectable, with distinct progress, completion, and cleanup retry states.

### Removed

- Remove the session history timeline, its call details, and related record navigation.
- Remove automatic overlay body dimming during collection and analysis preparation, delays, or errors.

### Fixed

- Fixed the overlay flickering or briefly disappearing during usage refreshes or log writes. ([#15](https://github.com/jisoq/Codexon/pull/15))
- Fixed expanded details redrawing and unnecessary activity indicators during background refreshes. ([#19](https://github.com/jisoq/Codexon/pull/19))
- Fixed usage analysis failing when startup checks took longer. ([#20](https://github.com/jisoq/Codexon/pull/20))
- Fixed collection appearing to be starting or delayed despite fresh collected records. ([#20](https://github.com/jisoq/Codexon/pull/20), [#22](https://github.com/jisoq/Codexon/pull/22))
- Fixed direct connection restoration failing with certain configuration paths or local address conflicts. ([#21](https://github.com/jisoq/Codexon/pull/21))
- Fixed Codexon failing to reopen after updates or ChatGPT reopening before its connection was ready. ([#22](https://github.com/jisoq/Codexon/pull/22))
- Fixed incorrect close confirmation and restart handling when retrying interrupted updates. ([#22](https://github.com/jisoq/Codexon/pull/22))
- Fixed temporary file access errors preventing update progress from being read. ([#22](https://github.com/jisoq/Codexon/pull/22))
- Fixed background processes remaining after ChatGPT windows closed and preventing updates from completing. ([#24](https://github.com/jisoq/Codexon/pull/24))
- Fixed the overlay settings window closing when choosing a row highlight style. ([1d5c3c8](https://github.com/jisoq/Codexon/commit/1d5c3c8fa079e67fde17b93bc96faff7a8c85ff1))

### Security

- Fixed a Windows Python package installation vulnerability that could create files outside the destination folder. ([GHSA-xmj3-9gf7-h52w](https://github.com/pypa/setuptools/security/advisories/GHSA-xmj3-9gf7-h52w))

**Update notes**

- The first launch after updating prepares usage analysis again while preserving usage records and saved mismatches.
- Finish and save ongoing work before confirming the restart required to replace an existing installation.

On Windows 10/11 x64, run **Codexon-Setup.exe** or update from **Settings → About**. Authentication and existing usage records are preserved. A disabled proxy remains disabled.

Qt/PySide6 6.11.2 sources reuse the existing fixed download location. A SHA-256 file accompanies the installer.
