## [2026.10.10.3] - 2026-10-10

### Added

- **Windows 충돌 후 재시작:** Windows 오류 보고 창에서 재시작을 선택하면 CPU 렌더링으로 대시보드를 엽니다. 기존 데이터 경로를 유지하며 별도 감시 프로세스는 추가하지 않습니다. 정상 종료와 업데이트 교체에서는 재시작 등록을 해제합니다.

  **Restart after a Windows crash:** Choosing restart in Windows Error Reporting opens the dashboard with CPU rendering and the same data locations. No watchdog process is added. Normal exit and update handoff unregister restart.

  실행 후 60초가 지나야 재시작 대상이 됩니다. 사용자 동의가 필요하며 Windows 정책에 따라 오류 창이 표시되지 않을 수 있습니다. 무인 자동 복구와 작업 관리자 강제 종료 복구는 보장하지 않습니다. `--software-rendering`으로 직접 실행할 수도 있습니다. CPU 렌더링에서는 성능과 일부 시각 효과가 달라질 수 있습니다.

  Restart eligibility requires at least 60 seconds of runtime and user consent. Windows policy can suppress the error dialog. Unattended recovery and recovery from Task Manager termination are not guaranteed. The `--software-rendering` option also enables CPU rendering manually; performance and some visual effects can differ.

### Changed

- **프로젝트와 세션 탐색:** 프로젝트 선택을 세션 계층에서 분리했습니다. 세션 기록의 경로와 표 구성을 정리하고, 대시보드의 필터와 상세 정보 배치를 개선했습니다.

  **Project and session navigation:** Project selection is separate from the session hierarchy. Session-history paths and tables are clearer, with improved dashboard filter and detail layouts.

### Fixed

- **작업표시줄 경고 색상:** 잔여량이 10% 미만일 때 밝은 작업표시줄과 어두운 작업표시줄에 맞는 경고 색상을 사용합니다. 앱 테마가 달라도 읽을 수 있는 대비를 유지합니다.

  **Taskbar warning colors:** Remaining allowance below 10% uses warning colors suited to light and dark taskbars, preserving readable contrast even when the app uses a different theme.

- **새 설치본 버전 구분:** 이전 로컬 설치본보다 높은 버전을 부여했습니다. 이번 변경을 기존 빌드와 구분하고 업데이트 대상으로 인식할 수 있습니다.

  **Distinct installer version:** This build has a higher version than the previous local installation, so updates can distinguish the new changes from that build.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 **설정 → 앱 정보**에서 업데이트하세요. 인증 정보와 기존 사용량 기록은 유지합니다. 프록시를 꺼 둔 경우 그대로 유지합니다.

On Windows 10/11 x64, run **Codexon-Setup.exe** or update through **Settings → About**. Authentication and existing usage records are preserved. A disabled proxy remains disabled.

GUI 충돌 시 별도 실행 중인 수집기와 프록시는 유지됩니다. 앱을 정상 종료하면 관리 중인 서비스를 정리합니다. 이번 변경이 모든 그래픽 드라이버 충돌을 예방한다는 뜻은 아닙니다.

Independently running collector and proxy processes remain available after a GUI crash. Normal app exit stops managed services. This change does not prevent every graphics-driver crash.

Qt/PySide6 6.11.2 소스는 기존 고정 다운로드 위치를 재사용합니다. 앱 실행에는 필요하지 않습니다. 설치 프로그램 다운로드에는 SHA-256 파일이 함께 제공됩니다.

The corresponding Qt/PySide6 6.11.2 sources reuse their existing locked download location and are not required to run the app. A SHA-256 file accompanies the installer download.
