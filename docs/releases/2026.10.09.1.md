이전 공개 릴리즈 **v2026.10.08.2** 이후 변경 사항입니다.

- **프록시 연결 정리와 장애 복구:** Windows의 소켓 처리 방식을 변경했습니다. 연결 종료가 겹칠 때 같은 연결을 여러 번 정리하지 않도록 했습니다. 치명적 오류는 진단 기록을 남긴 뒤 종료합니다. Codexon 실행 중에는 기존 재시작 정책에 따라 복구합니다.
- **한도 조회의 로그인 정보 보호:** 한도 조회가 별도의 Codex 인증 프로세스를 실행하지 않습니다. 기존 토큰만 읽으며 갱신 토큰이나 인증 파일을 변경하지 않습니다. 인증이 만료되면 ChatGPT 앱의 로그인 갱신을 기다립니다.
- **로그인 저장 방식 지원 범위:** 실시간 한도 조회는 Codex home의 `auth.json`에 저장된 로그인을 지원합니다. OS 자격증명 저장소와 메모리 전용 로그인은 로컬 관측 기록을 사용합니다. 기존 기록과 한도 원장은 보존합니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하세요. 업데이트 전 진행 중인 응답과 서버 호출을 마쳐 주세요. 기존 공통 데이터베이스나 `.codex` 폴더를 직접 삭제할 필요는 없습니다. 사용 방법은 [사용 안내](../user-guide.ko.md)를 참고하세요.

The Windows proxy uses Proactor socket handling and a single owner for overlapping connection closures. Fatal errors leave a diagnostic record and exit cleanly. Existing bounded restart recovery applies while Codexon is running.

Quota reads use the existing access token without launching another Codex authentication process. They never refresh tokens or modify authentication files. Expired authentication waits for renewal in the ChatGPT app.

Live quota reads support file-based credentials in the selected Codex home's `auth.json`. OS credential-store and memory-only login modes use local observations. Existing records and quota history are preserved.
