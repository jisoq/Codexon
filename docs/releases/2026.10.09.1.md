## [2026.10.09.1] - 2026-10-09

이전 공개 릴리즈 **v2026.10.08.2** 이후 변경 사항입니다.

### Added

- **프록시 장애 진단:** 치명적 오류가 발생하면 오류 유형과 연결 처리 단계를 기록합니다. 인증 정보와 대화 본문은 기록하지 않습니다.

  **Proxy failure diagnostics:** Fatal errors record the error type and connection-processing stages without authentication data or conversation content.

### Fixed

- **프록시 연결 종료 처리:** 연결 종료가 겹칠 때 같은 연결을 여러 번 정리하던 경로를 수정했습니다.

  **Proxy connection cleanup:** Fixed repeated cleanup of the same connection when connection closures overlap.

- **프록시 장애 후 복구:** 치명적 오류 후 프록시가 종료되어 기존 자동 복구 절차를 따르도록 했습니다. Codexon 실행 중 기존 재시작 조건을 충족하면 프록시를 다시 시작합니다.

  **Recovery after proxy failures:** Fatal errors now stop the proxy process so the existing recovery procedure can run. While Codexon is running, the proxy restarts when the existing restart conditions are met.

- **프록시 재시작 확인:** 이전 실행 기록만으로 재시작 성공을 판단하던 문제를 수정했습니다. 새 프록시가 정상 응답하는지 확인합니다.

  **Proxy restart verification:** Fixed restart success being inferred from a previous process's status record. Codexon now checks that the new proxy responds successfully.
