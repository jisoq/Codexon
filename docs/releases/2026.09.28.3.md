이전 공개 릴리즈 **v2026.09.27.1** 이후 변경 사항입니다.

- **사용 기록 미표시 수정:** 업데이트 후 사용 현황이 0호출·0세션으로 남던 기본 색인 경로 불일치를 수정했습니다. 기존 기본 색인은 새 위치에 색인이 없을 때 원본을 보존하며 이전합니다. 수집 결과를 읽지 못하면 계속 ‘수집 중’으로 표시하지 않고 원인을 안내합니다. ([#6](https://github.com/jisoq/Codexon/issues/6))
- **업데이트 후 수집기 복구:** 이전 수집기의 기본 경로 오류가 있어도 해당 수집기를 확인하고 정상 종료한 뒤 새 실행 파일로 전환합니다. 예약 작업을 수동으로 고치지 않아도 앱 재시작 후 같은 수집 경로를 사용하며, 사용자 지정 색인·모델 관측 경로는 유지합니다.
- **프록시 첫 연결 오류 수정:** 관측 DB가 아직 없는 상태에서 프록시를 켜면 `unable to open database file`로 실패하던 문제를 수정했습니다. 첫 검증 요청의 관측 기록이 저장된 뒤 연결 결과를 확인합니다.
- **연결 교체 대기 해소:** 업데이트 중 첫 상태 조회가 일시적으로 실패하면 종료 요청 없이 대기가 계속되던 문제를 수정했습니다. 상태 응답이 돌아오면 같은 작업기인지 다시 확인하고 전환을 진행하며, 진행 중인 응답은 보존합니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 앱의 **설정 → 정보·문제 해결 → 업데이트 확인 및 설치**를 사용하세요. 업데이트 전 진행 중인 응답과 서버 호출을 마쳐 주세요. 기존 데이터베이스나 `.codex` 폴더를 삭제할 필요는 없습니다. 사용 방법은 [사용 안내](https://github.com/jisoq/Codexon/blob/v2026.09.28.3/docs/user-guide.ko.md)를 참고하세요.

This release fixes empty usage history caused by inconsistent default index paths, preserves existing indexes during migration, and restores collection after updates. It also fixes first-time proxy verification before the observation database exists and resumes connection replacement after a temporary health-check failure.

`Codexon-third-party-source-6.11.2.zip` contains the corresponding Qt/PySide6 sources and is not required to run the app. SHA-256 files accompany the downloads.
