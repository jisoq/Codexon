## [2026.10.22.1] - 2026-10-22

- 알려진 제한: v2026.09.25.6에서 업데이트할 때 프록시 자동 교체가 간헐적으로 실패할 수 있습니다.

### Added

- 지표 비교에서 Standard와 Fast 요청을 나눠 보고, 모드별로 묶어 정렬할 수 있습니다.
- 검증 기록의 저장 위치를 지정하고 같은 조건으로 검증을 다시 실행할 수 있습니다.

### Changed

- 지표 비교의 이름 정렬을 개선하고 긴 모델 이름을 줄바꿈으로 표시합니다.
- 사용량을 갱신하는 동안 기존 값을 유지하고 해당 화면의 진행 표시로 상태를 확인할 수 있습니다.

### Fixed

- 표를 드래그한 뒤 화면이 멈추는 문제를 수정했습니다.
- 사용량 갱신 중 화면 배치가 흔들리는 문제를 수정했습니다.
- 오래 걸리는 작업의 영문 진행 안내에 한글이 섞이는 문제를 수정했습니다.
- 일부 Windows 작업 권한 설정에서 업데이트 마무리가 반복해서 실패하는 문제를 수정했습니다.
- 검증 기록 저장 오류가 실제 실패 원인을 가리는 문제를 수정했습니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 **설정 → 앱 정보**에서 업데이트하세요. 인증 정보와 기존 사용량 기록은 유지합니다. 프록시를 꺼 둔 경우 그대로 유지합니다.

Qt/PySide6 6.11.2 소스는 기존 고정 다운로드 위치를 재사용합니다. 설치 프로그램에는 SHA-256 파일이 함께 제공됩니다.

---

- Known limitation: Automatic proxy replacement can fail intermittently when updating from v2026.09.25.6.

### Added

- Compare Standard and Fast requests separately in metric comparisons and sort entries by request mode.
- Choose where verification records are saved and rerun verification under the same conditions.

### Changed

- Improved name sorting in metric comparisons and wrapped long model names onto multiple lines.
- Keep existing usage values visible during refreshes and show progress within the usage view.

### Fixed

- Fixed the interface becoming stuck after dragging a table.
- Fixed layout shifts while refreshing usage.
- Fixed Korean text appearing in English progress feedback for long-running operations.
- Fixed update completion repeatedly failing under certain Windows task permissions.
- Fixed errors saving verification records obscuring the original failure.

On Windows 10/11 x64, run **Codexon-Setup.exe** or update from **Settings → About**. Authentication and existing usage records are preserved. A disabled proxy remains disabled.

Qt/PySide6 6.11.2 sources reuse the existing fixed download location. A SHA-256 file accompanies the installer.
