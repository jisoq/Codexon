## [2026.10.16.2] - 2026-10-16

### Changed

- 지연 로딩 화면에 움직이는 진행 막대와 작업에 맞는 단계 안내를 추가했습니다.
- 같은 조건으로 새로고침할 때 기존 결과를 유지하도록 개선했습니다.
- 지표 비교와 성능 추이의 조회 및 반복 계산을 줄였습니다.
- 사용 기록 변경을 감지해 오버레이 갱신을 앞당기고 불필요한 재조회를 줄였습니다.

### Removed

- 구독 모니터링의 ‘전체 보기’ 버튼을 제거했습니다.

### Fixed

- 성능 추이에서 빈 화면과 로딩 안내가 반복되는 문제를 수정했습니다.
- 최신 Codex 기록 형식의 실행 모드 인식과 기존 기록 복구를 수정했습니다.
- 실행 모드가 확인된 기록의 비용 계산을 복구했습니다. 필수 토큰 정보가 없는 기록은 비용 미확인을 유지합니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 **설정 → 앱 정보**에서 업데이트하세요. 인증 정보와 기존 사용량 기록은 유지합니다. 프록시를 꺼 둔 경우 그대로 유지합니다.

Qt/PySide6 6.11.2 소스는 기존 고정 다운로드 위치를 재사용합니다. 설치 프로그램에는 SHA-256 파일이 함께 제공됩니다.

---

### Changed

- Added animated progress bars and task-specific stages to deferred loading screens.
- Existing results remain visible when refreshing with the same conditions.
- Reduced queries and repeated calculations in metric comparison and performance trends.
- Source-record changes trigger earlier overlay updates with fewer unnecessary queries.

### Removed

- Removed the “View all” button from subscription monitoring.

### Fixed

- Fixed repeated empty screens and loading messages in performance trends.
- Fixed execution-mode recognition and recovery of existing records for current Codex log formats.
- Restored cost calculation for records with a confirmed execution mode. Costs remain unknown when required token information is missing.

On Windows 10/11 x64, run **Codexon-Setup.exe** or update through **Settings → About**. Authentication and existing usage records are preserved. A disabled proxy remains disabled.

Qt/PySide6 6.11.2 sources reuse their existing locked download location. A SHA-256 file accompanies the installer.
