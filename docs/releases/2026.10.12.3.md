## [2026.10.12.3] - 2026-10-12

### Changed

- **수집과 분석 비용:** 변경된 요청과 관련 세션만 다시 계산합니다. 변경 없는 게시 결과와 사용 한도 집계를 재사용합니다. 대체된 상세 분석 요청은 합쳐 처리합니다. 정상 수집 주기는 3초로 유지합니다.

  **Collection and analysis cost:** Recalculates changed requests and related sessions, reuses unchanged published results and quota aggregates, and coalesces superseded detail requests. The normal collection interval remains three seconds.

- **큰 기록과 재시작:** 큰 로그를 나누어 읽고 변경 없는 미완성 꼬리는 반복해서 읽지 않습니다. 재시작 복원을 시간 예산 안에서 나누어 처리합니다. 관측 메모리를 제한하고 과거 근거는 저장된 기록에서 조회합니다.

  **Large histories and restart:** Reads large logs in bounded pieces without repeatedly reading an unchanged incomplete tail. Restart recovery runs in time-budgeted batches. Observation memory is bounded, while historical evidence remains available from stored records.

- **기간 선택:** 기간과 조작부를 한 줄로 정리했습니다. ‘새 기록 따라가기’를 켜면 최신 구간을 계속 따라갑니다. 끄면 선택한 기간을 유지합니다. 좁은 창에서는 표시를 줄여 가로 넘침을 방지합니다.

  **Period selection:** Places the period and controls on one row. Enable “Follow new records” to keep following the latest interval; disable it to retain the selected period. Compact labels prevent horizontal overflow in narrow windows.

- **오류와 알림 확인:** 현재 오류를 기록 표 위에 표시합니다. 기록 수에 맞춰 표 높이를 조정합니다. 긴 확인 근거는 생략 표시와 상세 조회로 확인합니다. 검색창 안에서 검색어를 지울 수 있습니다.

  **Errors and notifications:** Shows current errors above the history table and sizes the table to its record count. Long evidence uses ellipsis and detail access. Search text can be cleared inside the search field.

- **오버레이 지연 진단:** 분석 지연, 수집 지연, 수집 오류와 서비스 오류를 구분해 표시합니다. 마지막 확인 시각은 전체 분석 없이 갱신합니다. 간헐적으로 나타나는 배너의 실제 원인은 아직 확정하지 못했습니다.

  **Overlay delay diagnostics:** Distinguishes analysis delay, collection delay, collection errors, and service errors. The last-checked time refreshes without a full analysis. The cause of the intermittent banner has not yet been established.

- **트레이 표시:** 잔여량 숫자를 제거하고 로고 크기를 조정합니다. 경고와 오류 표시, 작업표시줄 잔여량 위젯과 툴팁은 유지합니다.

  **Tray display:** Removes the remaining-quota number and adjusts the logo size. Warning and error indicators, the taskbar quota widget, and tooltips remain available.

### Fixed

- **오류 복구 표시:** 정상 상태가 확인된 백그라운드 오류를 해제합니다. 사용자 설정 작업의 실패는 별도로 유지합니다. 저장 오류는 실제 저장 성공을 확인한 뒤 해제합니다.

  **Error recovery status:** Clears background errors after confirmed recovery while retaining failed user settings operations separately. Storage errors clear only after a confirmed successful write.

- **업데이트와 연결:** 업데이트 완료 후 불필요한 ChatGPT 재시작 안내를 제거합니다. 앱 재시작 중 연결이 끊겨도 프록시는 새 연결을 계속 받습니다. 진행 중인 응답을 보존하며 요청을 재전송하지 않습니다.

  **Updates and connections:** Removes the unnecessary ChatGPT restart instruction after an update completes. The proxy continues accepting connections when a client disconnects during app restart. In-flight responses are preserved without replaying requests.

### Known limitations

- **큰 로그의 보호 한도:** 분할해서 해석하는 로그의 선택된 필드 값은 16 MiB로 제한합니다. 이 경로의 JSON 중첩은 128단계로 제한합니다. 한도를 넘으면 오류를 표시합니다.

  **Large-log safeguards:** Selected field values in incrementally parsed logs are limited to 16 MiB, with JSON nesting limited to 128 levels on this path. Exceeding either limit reports an error.
