이전 공개 릴리즈 **v2026.10.01.2** 이후 변경 사항입니다.

- **에이전트별 호출 그래프:** 비용, 캐시 적중률, 출력 속도, 추론 토큰 그래프는 같은 에이전트의 호출끼리 연결합니다. 다른 에이전트의 호출이 사이에 있어도 해당 에이전트의 선을 이어 표시하며, 네 그래프에서 같은 에이전트에 같은 색상을 사용합니다. 출력 속도는 모델과 실행 조건이 바뀌면 선을 끊습니다.
- **오버레이 상태 안내:** 원격 작업, 기록 불러오기, 호출 기록 없음 상태를 별도 안내 카드로 표시합니다. 로컬 기록이 없는 원격 작업은 이유를 안내하고, 갱신 지연이나 오류가 있을 때는 마지막 확인 시점을 표시합니다.
- **한도 수집 대기:** 한도 기록을 아직 수집하지 못한 상태에서는 빈 그래프와 0으로 보이던 합계를 숨기고 수집 대기 안내를 표시합니다. 실제로 확인된 사용량 0과 구분합니다.
- **기록 검색 초기화:** 검색어나 필터 때문에 기록이 보이지 않으면 원인을 안내합니다. 결과 영역에서 검색 지우기와 필터 초기화를 바로 실행할 수 있습니다.
- **업데이트와 프록시 상태:** 업데이트 확인 실패를 최신 버전 확인 결과와 구분하고 마지막 성공 시점과 오류 상세 정보를 제공합니다. 사용자가 프록시를 해제한 상태는 장애처럼 표시하지 않습니다.
- **구독 가치 환산 안내:** Standard API 단가와 구독 차감 배율의 기준을 구분해 표시합니다. 구독 배율이 확인되지 않은 모델과 모드 조합은 미확인 값으로 처리합니다. 표시 금액은 실제 구독 청구액이 아닙니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 앱의 **설정 → 앱 정보**에서 업데이트를 확인하세요. 업데이트 전 진행 중인 응답과 서버 호출을 마쳐 주세요. 기존 공통 데이터베이스나 `.codex` 폴더를 직접 삭제할 필요는 없습니다. 사용 방법은 [사용 안내](https://github.com/jisoq/Codexon/blob/v2026.10.02.2/docs/user-guide.ko.md)를 참고하세요.

All four recent-call charts now connect calls from the same agent and use consistent colors per agent. Output-speed lines stop when the model or execution conditions change.

The overlay distinguishes remote tasks without local records, loading and empty history, and shows the last confirmation time when updates are delayed or fail. Quota pages distinguish missing observations from confirmed zero usage. Empty search results provide actions to clear the search or reset filters. Update-check errors no longer look like successful checks, and an intentionally disabled proxy is distinguished from a failure.

Subscription-value estimates distinguish Standard API rates from subscription usage multipliers. Unsupported multiplier combinations remain unknown. Displayed amounts are estimates, not subscription charges.

`Codexon-third-party-source-6.11.2.zip` contains the corresponding Qt/PySide6 sources and is not required to run the app. SHA-256 files accompany the downloads.
