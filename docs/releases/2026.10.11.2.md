## [2026.10.11.2] - 2026-10-11

### Changed

- **수집 비용:** 변경된 세션과 활동 기록만 전송합니다. 변경 없는 이관 기록과 활동 집계는 재사용합니다. 큰 파일의 이어읽기와 검증을 나누어 처리합니다.

  **Collection cost:** Only changed sessions and activity records are transferred. Unchanged imported history and activity aggregates are reused. Large-file reading and validation run in bounded slices.

- **제외 구간 편집:** 구간 선택 중 예상 가치 미리 계산을 제거했습니다. 적용 후 재집계 결과를 확인할 수 있습니다.

  **Exclusion editing:** Estimated-value previews are no longer calculated while selecting an interval. Recalculated results remain available after applying the exclusion.

- **관측 저장:** 새 주간 관측의 중복 저장과 변경 없는 상태의 반복 쓰기를 줄였습니다. 기존 관측과 조회 결과는 유지합니다.

  **Observation storage:** New weekly observations avoid duplicate storage, and unchanged state avoids repeated writes. Existing observations and query results are preserved.

### Fixed

- **수집 복구:** 수집기가 중단되어도 저장된 상태에서 복구합니다. 원본 수정, 기록 삭제, 재연결을 반영하며 기존 기록을 중복 집계하지 않습니다.

  **Collection recovery:** An interrupted collector resumes from saved state. Source corrections, record removal, and reconnection are reflected without counting existing records twice.

- **저장 장애:** 관측과 추적 설정 변경을 순서대로 보관하고 재시작 후 복구합니다. 복구 DB는 홈별 최대 16 MiB입니다. 대기 용량에 도달하면 새 계정 조회를 중지하고 상태를 표시합니다. 임시 저장도 실패하면 종료 전 저장 공간을 확보해야 합니다.

  **Storage outages:** Observations and tracking changes are retained in order and recovered after restart. Each home's recovery database is limited to 16 MiB. At backlog capacity, new account reads pause and the condition is shown. If temporary storage also fails, free storage before closing the app.

- **취소 응답:** 취소된 응답의 추적 상태와 시간 정보를 해제합니다. 취소 완료가 활동 기록에도 반영됩니다.

  **Cancelled responses:** Cancelled responses release tracking state and timing data. Activity history also recognizes cancellation as a terminal state.

On Windows 10/11 x64, run **Codexon-Setup.exe** or update through **Settings → About**. Authentication and existing usage records are preserved. A disabled proxy remains disabled.
