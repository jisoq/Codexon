## [2026.10.18.2] - 2026-10-18

### Changed

- 오버레이의 Main Agent 사용량과 오른쪽 Sub Agents 사용량을 분리했습니다.
- Trend에서 하위 에이전트를 포함한 최근 20호출을 에이전트별 색상으로 표시합니다.

- 펼친 상세 항목의 평균 출력 속도와 비용 및 토큰 수량을 한 줄씩 표시합니다.
- 준비, 지연, 오류 상태를 세션 제목 옆에 모으고 갱신이 원활하지 않으면 기존 값을 흐리게 표시합니다.
- 구독 주기 표에서 환산액과 소모율을 함께 표시합니다.
- README 이미지와 설명을 최신 화면에 맞췄습니다.

### Fixed

- 상세 항목을 누른 뒤 헤더 버튼과 호버가 반응하지 않거나 툴팁이 가려지는 문제를 수정했습니다.
- 상세 패널을 닫으면 오른쪽까지 이동할 수 있고, 다시 열 때 공간이 부족하면 위치를 조정합니다.
- 업데이트 직후 기록 준비를 수집 오류와 구분하고 초기 준비 중 불필요한 대기를 줄였습니다.
- 구독 차트가 갱신 중 멈추는 문제와 조회 실패 후 이전 잔여량이 정상값처럼 보이는 문제를 수정했습니다.
- 직접 입력한 조회 기간을 적용 전에 확인하고, 비교에서 연 기록의 조회 범위를 유지합니다.
- 좁은 창에서도 성능 차트를 확인하고 모델 목록과 구간 분석을 펼칠 수 있습니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 **설정 → 앱 정보**에서 업데이트하세요. 인증 정보와 기존 사용량 기록은 유지합니다. 프록시를 꺼 둔 경우 그대로 유지합니다.

Qt/PySide6 6.11.2 소스는 기존 고정 다운로드 위치를 재사용합니다. 설치 프로그램에는 SHA-256 파일이 함께 제공됩니다.

### Added

- Added Home with remaining allowance, today's usage, and links to the main features.

### Changed

- Separated Main Agent usage from the right-side Sub Agents panel in the overlay.
- Trend now shows the 20 most recent calls, including subagents, with a color for each agent.
- Sub Agents shows value and agent count, with agents ordered by recent updates and an alternative model grouping.
- Expanded details show average output speed and each cost and token amount on a single line.
- Grouped preparation, delay, and error messages beside the session title and dimmed existing values when updates are interrupted or delayed.
- The subscription cycle table now shows value and allowance consumption together.
- Updated README images and descriptions to match the current interface.

### Fixed

- Fixed header buttons and hover feedback becoming unresponsive, and tooltips being obscured, after interacting with details.
- The closed overlay can move to the right edge and adjusts its position when reopened details need more room.
- Distinguished record preparation from collection errors after updates and reduced unnecessary startup waits.
- Fixed subscription charts stalling during updates and old allowance values appearing current after a failed lookup.
- Validate manually entered date ranges before applying them and retain the scope of records opened from comparisons.
- Kept performance charts usable in narrow windows with expandable model lists and interval analysis.

On Windows 10/11 x64, run **Codexon-Setup.exe** or update through **Settings → About**. Authentication and existing usage records are preserved. A disabled proxy remains disabled.

Qt/PySide6 6.11.2 sources reuse their existing locked download location. A SHA-256 file accompanies the installer.
