## [2026.10.13.2] - 2026-10-13

### Changed

- **Home과 지표 비교:** Home에서 전체 호출과 토큰 사용량, 구독 가치 환산액을 확인합니다. 지표 비교에서 프로젝트, 모델, 작업 종류, 추론 설정, 요청 모드별 사용량을 조회합니다. 항목을 선택하면 관련 상세와 세션 기록으로 이동합니다. 기존 조건 비교 화면은 지표 비교로 교체합니다.

  **Home and metric comparison:** Home shows total calls, token usage, and subscription-equivalent value. Metric comparison groups usage by project, model, work type, reasoning setting, or request mode. Select an item to inspect its details and session records. Metric comparison replaces the previous condition comparison screen.

- **세션 기록 탐색:** 프로젝트 목록을 접고 펼칠 수 있습니다. 조회 조건을 팝업에서 조정하고 적용된 조건을 개별 해제합니다. 세션 자체 기록과 하위 세션 포함 합계를 구분합니다. 좁은 창의 표 너비와 긴 소요시간 표시를 개선합니다.

  **Session history navigation:** The project list can be collapsed. Query conditions open in a popup, and active conditions can be removed individually. Summaries distinguish a session's own records from totals including child sessions. Table sizing in compact windows and long-duration formatting are improved.

- **구독 모니터링 갱신:** 변경된 집계 주기를 다시 계산하고 선택한 그래프만 화면으로 전달합니다. 변경 없는 그래프는 재사용합니다. 과거 기록 수정과 삭제, 제외 설정 변경은 집계에 반영합니다. 집계 정확도와 기존 수집 주기는 유지합니다.

  **Subscription monitoring refresh:** Recalculates changed accounting cycles and transfers only the selected graph to the interface. Unchanged graphs are reused. Historical corrections, deletions, and exclusion changes remain reflected in the totals. Aggregation accuracy and the existing collection interval are preserved.

- **기록 복원과 수집:** 계속 증가하는 로그의 검증 진행을 보존합니다. 복원된 세션의 사용량은 검증이 끝나는 대로 표시합니다. 기록 재생과 변경 없는 저장 작업을 줄입니다. Windows 수집 통신에는 사용자 전용 파이프를 사용합니다. 지연 진단 기록의 보관량을 제한합니다.

  **History recovery and collection:** Preserves verification progress for growing logs and displays recovered session usage as soon as it is verified. Reduces history replay and unchanged storage work. Windows collection communication uses private user pipes, and retained delay diagnostics are bounded.

- **구독 요약과 트레이:** 사용 한도 화면을 구독 모니터링으로 표시합니다. 좁은 요약 카드의 긴 값을 맞추고 측정 시작 시각을 유지합니다. 잔여 할당량이 낮다는 이유만으로 트레이 경고 배지를 추가하지 않습니다.

  **Subscription summaries and tray:** Renames the usage-limit screen to subscription monitoring. Long values fit compact summary cards, and the measurement start time is retained. Low remaining quota alone no longer adds a tray warning badge.

### Fixed

- **탭 전환 지연:** 세션 기록에서 구독 모니터링으로 이동할 때 숨겨진 조회 조건을 반복 생성하던 경로를 수정합니다.

  **Tab switching delay:** Fixes repeated recreation of hidden history filters when switching from session history to subscription monitoring.

- **로딩 중 조작부:** 구독 모니터링과 선택한 그래프를 불러오는 동안 제외 관리 버튼과 모델 범례를 숨깁니다. 사용할 데이터가 준비되면 함께 표시합니다.

  **Controls during loading:** Hides exclusion management and the model legend while subscription monitoring or the selected graph is loading. The controls appear together when usable data is ready.

- **검증과 설치 준비:** CI 검증 진행과 설치 후보를 재사용합니다. 재시도 과정에서 검사 프로세스의 상위 프로세스를 보호합니다. 설치 검증의 인증서 처리와 임시 저장 위치를 수정합니다.

  **Verification and installation preparation:** Reuses CI verification progress and installer candidates. Retry cleanup protects parent processes of checks. Fixes certificate handling and temporary storage placement in installation verification.

### Known limitations

- **캐시와 최초 조회:** 입력 캐시 예산을 초과하거나 변경 기록이 이어지지 않으면 원본을 다시 읽습니다. 최초 조회와 전체 기간 그래프 계산에는 시간이 걸릴 수 있습니다. 값을 생략하거나 집계 정확도를 낮추지 않습니다.

  **Cache and initial queries:** Source data is read again when the input cache budget is exceeded or the change history is discontinuous. Initial queries and all-period graph calculation can still take time. Values are not omitted, and aggregation accuracy is not reduced.
