이전 공개 릴리즈 **v2026.10.08.1** 이후 변경 사항입니다.

- **수집과 로딩 상태 안내:** 로컬 기록을 처음 읽는 동안 빈 그래프 대신 수집 중 안내를 표시합니다. 다른 화면으로 이동하면 해당 화면의 로딩 상태를 보여 줍니다. 같은 조건의 최신 기록을 반영할 때는 기존 결과를 유지합니다. 계산이 길어지면 진행 중임을 알리고, 실패하면 다시 시도할 수 있습니다.
- **사용 한도 화면 정리:** 크레딧 잔액과 사용 초기화권을 간결하게 배치했습니다. 초기화권은 가까운 만료일을 먼저 표시하고, 나머지 항목과 지급 정보는 필요할 때 펼칠 수 있습니다. 날짜와 함께 시간대를 표시합니다.
- **한도 그래프와 상세 정보:** 그래프 높이를 늘리고, 축 여백 때문에 음수 눈금이 나타나지 않도록 했습니다. 같은 기록을 다시 받았을 때 기존 그래프를 재사용합니다. 선택 위치를 움직일 때 상세 정보와 안내선이 함께 갱신됩니다.

직전 버전의 성능 추이 개편과 크레딧 잔액 소수점 표시 수정도 모두 포함합니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 앱의 **설정 → 앱 정보**에서 업데이트를 확인하세요. 업데이트 전 진행 중인 응답과 서버 호출을 마쳐 주세요. 기존 공통 데이터베이스나 `.codex` 폴더를 직접 삭제할 필요는 없습니다. 사용 방법은 [사용 안내](https://github.com/jisoq/Codexon/blob/v2026.10.08.2/docs/user-guide.ko.md)를 참고하세요.

Initial local-record collection now shows a collection notice instead of empty charts. Page changes show the relevant loading state. Background refreshes keep existing results for the same selection. Longer calculations show their progress state, and failed loads offer a retry action.

The usage-limit page presents credit balances and reset credits more compactly. Reset credits show the nearest expirations first, with additional entries and grant information available on expansion. Dates include their time zone.

Quota charts are taller and avoid negative axis padding. Repeated identical records reuse the rendered graph. Moving the inspection position updates its guide and detailed values together.

This release also includes all performance-control and credit-formatting changes from the previous release.

`Codexon-third-party-source-6.11.2.zip` contains the corresponding Qt/PySide6 sources and is not required to run the app. SHA-256 files accompany the downloads.
