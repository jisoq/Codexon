## [2026.10.14.1] - 2026-10-14

### Added

- 구독 모니터링을 일시정지하고 재개할 수 있습니다. 정지 중에는 한도 조회와 자동 집계를 멈춥니다.
- Home에서 최근 화면의 미리보기를 확인할 수 있습니다.

### Changed

- 모델 비교와 좁은 창의 탐색 동작을 개선했습니다.
- 업데이트와 종료 과정의 진행 안내를 명확하게 표시합니다.
- Pro 계정에서 서버가 확인한 5시간 무제한 상태와 크레딧 잔액을 표시합니다.
- 많은 세션과 사용 한도 이력을 반복 조회할 때 불필요한 계산을 줄였습니다.
- 세션에 연결되지 않은 진단 기록은 최근 30분만 보관하며, 용량 초과 시 일부 기록을 생략합니다.

### Fixed

- 완료된 프록시 요청의 빈 대기열이 남는 문제를 수정했습니다.
- 한도 조회 시간 초과의 실패 단계와 대기 시간을 진단 기록에 남깁니다. 일시적인 조회 실패 자체를 방지하지는 않습니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 **설정 → 앱 정보**에서 업데이트하세요. 인증 정보와 기존 사용량 기록은 유지합니다. 프록시를 꺼 둔 경우 그대로 유지합니다.

Qt/PySide6 6.11.2 소스는 기존 고정 다운로드 위치를 재사용합니다. 설치 프로그램에는 SHA-256 파일이 함께 제공됩니다.

### Added

- Subscription monitoring can be paused and resumed. Pausing stops account quota polling and automatic calculations.
- Home shows previews of recently visited screens.

### Changed

- Improved model comparisons and navigation in compact windows.
- Clarified progress messages during updates and shutdown.
- Shows server-confirmed unlimited five-hour usage and credit balances for Pro accounts.
- Reduced redundant calculations when repeatedly reading large session and quota histories.
- Unassigned diagnostic records are retained for 30 minutes, with some records omitted when capacity limits are reached.

### Fixed

- Removed empty queues left behind by completed proxy requests.
- Quota timeout diagnostics now record the failed RPC stage and elapsed wait. This does not prevent temporary lookup failures.

On Windows 10/11 x64, run **Codexon-Setup.exe** or update through **Settings → About**. Authentication and existing usage records are preserved. A disabled proxy remains disabled.

Qt/PySide6 6.11.2 sources reuse their existing locked download location. A SHA-256 file accompanies the installer.
