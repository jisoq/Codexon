이전 공개 릴리즈 **v2026.10.04.1**에서 보고된 [이슈 #8: 새 대화 사용량 수집 중단](https://github.com/jisoq/Codexon/issues/8)을 수정한 핫픽스입니다.

- **새 대화 사용량 수집 복구:** 종료된 수집기의 프로세스 번호가 다른 프로그램에 재사용되면 수집기를 다시 시작하지 못하던 문제를 수정했습니다. 구버전 수집 기록이 남은 경우에도 종료 상태를 확인해 수집을 재개합니다. 기존 대화 기록과 사용량 색인은 유지합니다.
- **수집 실패와 대기 상태 구분:** 새 대화가 아직 수집되지 않았어도 오버레이에 수집 오류, 갱신 지연, 시작 상태를 표시합니다. 시작 명령을 보낸 뒤에는 새 수집 결과와 실행 상태를 확인하며, 마지막 확인 시각은 실제 수집 기록을 기준으로 표시합니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 앱의 **설정 → 앱 정보**에서 업데이트를 확인하세요. 업데이트 전 진행 중인 응답과 서버 호출을 마쳐 주세요. 기존 공통 데이터베이스나 `.codex` 폴더를 직접 삭제할 필요는 없습니다. 사용 방법은 [사용 안내](https://github.com/jisoq/Codexon/blob/v2026.10.05.1/docs/user-guide.ko.md)를 참고하세요.

This hotfix resolves [issue #8](https://github.com/jisoq/Codexon/issues/8), restoring usage collection when Windows reuses a stopped collector's process ID for another application. It also handles retained records from older collectors while preserving conversation logs and the usage index.

The overlay now distinguishes collection errors, delayed results, and startup from waiting for call records, including for conversations that have not been collected yet. Collector startup is confirmed through new results and process checks. Confirmation times come from collection records rather than display refreshes.

`Codexon-third-party-source-6.11.2.zip` contains the corresponding Qt/PySide6 sources and is not required to run the app. SHA-256 files accompany the downloads.
