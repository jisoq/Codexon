이전 공개 릴리즈 **v2026.09.29.4** 이후 변경 사항입니다.

- **메모리 사용 감소:** 사용량 수집과 분석에서 같은 자료를 여러 번 보관하는 부분을 줄였습니다. 과거 기록, 비용 계산과 호출 상세는 유지합니다.
- **화면 생성 지연:** 대시보드 페이지와 보조 창을 필요할 때 생성합니다. 처음 여는 화면에는 짧은 생성 시간이 생길 수 있으며, 다시 방문할 때는 화면 상태와 스크롤 위치를 유지합니다.
- **백그라운드 작업 감소:** 숨긴 화면의 불필요한 계산과 같은 내용의 반복 저장을 줄였습니다. 한도 보고서 조회와 분석 결과 재사용도 개선했습니다.
- **설치 언어 유지:** 설치기를 다시 실행하는 내부 단계에 선택한 언어를 전달합니다. 일반 설치에서 언어를 두 번 묻던 문제를 수정했으며, 자동 업데이트에서도 선택값을 유지합니다.
- **모델 확인 안내와 한도 예시:** 한국어와 영어 README에 모델명 비교 안내와 실제 로컬 기록으로 만든 주간 한도 차트를 추가했습니다. API 환산 추정액과 공식 청구액의 차이도 설명합니다.

메모리 사용량은 기록 수와 연 화면에 따라 달라집니다. 변경 감지를 위한 수집기 계산 시간은 일부 늘어날 수 있습니다.

Windows 10/11 x64에서 **Codexon-Setup.exe**를 실행하거나 앱의 **설정 → 앱 정보**에서 업데이트를 확인하세요. 이전 설정 화면에서는 **설정 → 정보 및 문제 해결**에서 업데이트를 확인할 수 있습니다. 업데이트 전 진행 중인 응답과 서버 호출을 마쳐 주세요. 기존 데이터베이스나 `.codex` 폴더를 삭제할 필요는 없습니다. 사용 방법은 [사용 안내](https://github.com/jisoq/Codexon/blob/v2026.09.29.7/docs/user-guide.ko.md)를 참고하세요.
