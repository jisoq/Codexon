## [2026.10.10.1] - 2026-10-10

### Added

- **업데이트 진행 안내:** 앱 정보에서 준비부터 프록시 적용 완료까지 확인할 수 있습니다. 진행 중인 응답을 기다리고, 필요한 경우에만 연결한 앱의 정상 종료를 안내합니다. 실제 연결이 종료되면 자동으로 계속합니다.

  **Guided updates:** About shows progress from preparation through proxy activation. Updates wait for active responses and ask you to close the connected app normally only when necessary. They continue automatically after those connections close.

- **이어지는 업데이트 작업:** 앱이 다시 실행돼도 같은 업데이트 작업을 표시합니다. 본체 설치 후 연결 적용이 남으면 부분 완료로 표시합니다. 연결 적용에 실패하거나 나중으로 미룬 경우 해당 단계부터 다시 적용할 수 있습니다.

  **Resumable updates:** The same update operation remains visible after the app restarts. If installation finishes before the connection update, the app shows partial completion. Failed or deferred connection updates can resume from that stage.

### Changed

- **설정 구성과 바로가기:** 설정을 다섯 탭으로 재구성했습니다. 업데이트는 앱 정보에서, 연결 복구는 Codex 연결에서 관리합니다. 버전 번호를 누르면 해당 릴리즈가 열립니다. 사용 안내와 저장소는 아이콘으로 열 수 있습니다.

  **Settings and shortcuts:** Settings are organized into five tabs. About owns updates, while Codex connection owns connection recovery. Each version number opens its release page. User-guide and repository links use compact icons.

- **상위 설정과 하위 항목:** 관련 항목을 들여쓰고, 서로 다른 항목 묶음만 구분선으로 나눴습니다. 상위 알림이나 작업표시줄 위젯을 끄면 하위 제어도 비활성화됩니다. 기존 선택은 유지합니다. 값과 버튼은 설명을 포함한 행의 중앙에 맞췄습니다.

  **Parent and child settings:** Related controls are indented, with dividers between independent groups. Turning off notifications or the taskbar widget disables the dependent controls while preserving their values. Values and buttons are centered against the complete label and description.

- **필요한 상태와 동작 표시:** 프록시 실행 상태를 토글 옆에 표시합니다. 실행 중은 초록색, 꺼짐은 회색입니다. 업데이트 확인과 시작 버튼은 동시에 표시하지 않습니다. 취소와 나중에 적용은 별도 동작으로 제공합니다.

  **Relevant status and actions:** Proxy status appears beside its switch, using green for running and gray for off. Check for updates and Start update are not shown together. Cancel and Apply later remain separate actions.

- **화면 문구 정리:** 화면과 알림의 구분 표기를 정리했습니다. 상태 설명과 사용자 행동 안내를 구분하고, 한국어와 영어 표현을 맞췄습니다.

  **Clearer wording:** Separators are consistent across the interface and notifications. Status descriptions are distinguished from instructions, with equivalent Korean and English wording.

### Fixed

- **응답 중단 후 교체 대기:** 응답 중단 요청 때문에 연결이 미분류 상태로 남던 문제를 수정했습니다. 중단 요청만으로 응답을 완료 처리하지 않습니다. 마지막 응답 전달과 관측 기록 저장을 기다린 뒤 교체합니다.

  **Update waits after interruption:** Response interruption requests no longer leave the connection classified as unknown. An interruption request does not mark a response complete. Replacement waits for final response delivery and observation-record storage.

- **교체 검증과 실패 복원:** 버전이 같아도 실행 경로와 파일 해시로 설치본을 구분합니다. 새 프록시의 실행 상태를 연속 확인한 뒤 완료 처리합니다. 교체에 실패하면 이전 프록시를 복원하고 결과를 확인합니다. 교체가 시작된 뒤에는 취소가 검증이나 복원을 중단하지 않습니다.

  **Replacement verification and rollback:** Executable paths and hashes distinguish installations even when their version numbers match. Completion requires consecutive readiness checks of the new proxy. Failed replacements restore and verify the previous proxy. Once replacement begins, cancellation cannot interrupt verification or rollback.

- **Windows 프록시 종료와 오류 복구:** 연결을 정리할 때 같은 소켓을 중복 종료하거나 종료한 연결이 남아 보이던 경우를 수정했습니다. 치명적인 실행 오류를 정상 종료와 구분해 기록하고, 관리 프로세스가 복구할 수 있도록 했습니다.

  **Windows proxy shutdown and recovery:** Connection cleanup no longer closes the same socket twice or leaves closed connections counted as active in the affected cases. Fatal runtime failures are recorded separately from normal shutdown so the managing process can recover.
