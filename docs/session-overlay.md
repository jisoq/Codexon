# Codex 세션 오버레이

CacheMonitor가 외부 Qt Quick 창으로 표시하며 Codex 설치본·설정은 수정하지 않는다.
세션 선택은 지원되는 로컬 데스크톱 로그, 사용량은 기존 분석 엔진의 실제 호출 기록을 읽는다.
분석 과정이나 화면 갱신을 위해 모델 API를 호출하지 않는다.

## 화면과 크기

- 모니터: 기본 구성에서 350×542 논리 픽셀. 미분류, 환산 확인분, 캐시 미적중 안내는 실제 표시할 때만 높이를 추가하며 탭 전환 시 높이가 바뀌지 않는다.
- 상세: 오른쪽 모니터를 유지하고 왼쪽240px을 추가한다. 오른쪽·아래 경계 고정.
- 높이 부족: 상단 구성을 유지하는 432px 높이. 하단만 휠 또는 방향키로 스크롤한다. 더 부족하면 32px 아이콘.
- 왼쪽 추가 공간이 부족하면 모니터 폭 안에서 상세를 표시한다. 저장 위치를 밀어내지 않는다.
- 기본 창 경계 여백16px. 모니터 좌우 외곽 여백12px, 본문 들여쓰기8px, 입력과 출력 사이 간격16px, 지표 열 간격12px. Codex UI 글꼴이14px보다 크면 내부 전체를 비례 확대하고 OS 배율은 창 경계에서 한 번만 적용한다.

모니터 헤더에는 실제 세션 제목과 상세·투명도·최소화 버튼을 둔다. 위아래 외곽 여백은16px, 헤더와 세션 제목 사이 간격은12px, 카드 앞뒤와 모델 호출 구역 경계 간격은16px이다. 현재 탭의 모델 정보, 주요 지표, 소요시간, 입출력 묶음은 최근 탭과 같은200px 본문 높이에 배치하고 하단에 남는 여백을 묶음 사이로 분배한다. 하단 상태 문구가 어느 탭에도 없으면 해당 예약 행을 없애고16px 외곽 여백만 둔다. 상태 문구가 있으면 두 탭에 같은 높이를 확보한다.
상단에는 비용(API 단가 환산액), 입력 가중 캐시 적중률, 완료 호출의 평균 출력 속도와 입력/출력 구성을 고정한다. 구성 제목은 생략하고 모델 호출 영역 위에 얇은 구분선을 둔다.
상단 `세션`은 하단 `모델 호출`과 같은 글자 크기와 굵기를 사용한다. 호출 수와 하위 세션 포함 문구는 제목 옆의 작고 옅은 보조 텍스트로 표시한다. 하위가 없으면 포함 문구를 생략한다.
두 영역의 본문은 제목보다 8px 들여쓴다. 상단 비용, 캐시 적중률, 평균 출력 속도는 하나로 이어진 배경 카드 위에 표시한다. 카드는 섹션 전체 폭326px과 높이64px을 사용하며 본문과 같은 위치에 수치를 정렬한다. 카드와 구성 제목 사이 간격은16px이며 구성 전환은 세션 제목 행 오른쪽에 배치한다. 구성 끝과 구분선 사이 간격은16px이다.
세션 제목 행 우측의 작은 알약형 `개수 / $` 전환은 구성 수량과 비중만 바꾼다. 환산액은 산정 가능한 호출만 합쳐 상단 총액과 맞춘다.
하단 우측 알약형 `현재 / 최근` 전환은 가장 최근에 확인된 호출 결과와 최근12호출 추이를 전환한다. 저장된 선택이 없으면 현재가 기본이며 두 선택은 설정에 저장한다.
최신 호출의 모델과 일치 여부, 추론 강도, 요청 모드, 확인된 연결 방식은 현재 화면에서만 표시한다. 호출의 세션 제목과 시각은 모니터에서 제거하고 상세와 실제 이동 대상에 보존한다.
모델 일치 시 `호출모델명 (일치)`, 불일치 시 `호출모델명 (응답: 응답모델명)`으로 표시한다. 불일치는 테마 오류색과 굵은 글씨로 강조하고 일치의 괄호는 보조색이다. 비교할 수 없으면 `(확인 불가)`를 붙이고 설정 기록만 있으면 `설정:` 출처를 유지한다.
현재 화면의 주요 지표는 각 열 중앙에, 소요시간은 전체 폭 중앙에 정렬한다. 그 아래 입력/출력 두 열에는 합계, 작은 구성 막대, 캐시 읽기/추론 수량을 배치한다. 막대 분모는 각 입력/출력 합계이며 미확인이나 충돌은 비율을 만들지 않는다.
세션 합계와 최근 호출의 범위를 구별하며 요청 턴 합계나 계정 한도는 이 화면에 추가하지 않는다.

토큰 구성은 입력과 출력을 나눈 두 개의100% 누적 막대다. 입력 막대의 분모는 입력 합계, 출력 막대의 분모는 출력 합계다.
입력은 캐시 읽기·캐시 쓰기·일반 입력, 출력은 추론·추론 외 순서로 구분한다. 합계는 Total로 표시하며 대시보드에서도 같은 명칭과 순서를 사용한다. 0도 표시하고 미관측을0으로 대체하지 않는다.
미분류는 입력·출력 각각 실제 존재할 때 추가한다. 총량과 범주별 수량은 K/M으로 줄이고 정확한 정수는 호출 상세에 남긴다.
높이 부족으로 토큰 구성을 상세로 옮기면208px 콘텐츠 너비에서 입력·출력을 세로로 배치한다. 모니터 폭 안의 상세는326px의 두 열을 유지한다.
캐시 미적중 안내는 `캐시 미적중 2회: 해당 입력 66.6K`처럼 한 줄로 표시한다. 본 세션만 집계하고 하위 세션이 있으면 `본 세션`을 붙인다. 미적중이 없으면 안내 행과 여백 및 링크를 모두 제거한다.

이동 진입점은 목적지마다 대표 제목 하나만 사용한다.
- 모니터 `세션`: 현재 세션 기록 목록을 최신순으로 연다.
- 헤더 상세 버튼: 현재 탭은 최신 호출, 최근 탭은 고정 호출(없으면 최신 호출)의 상세를 열고 닫는다. `모델 호출`은 일반 제목이다.
- 상세 `호출 상세`: 선택 호출의 대시보드 전체 상세를 연다.
- 수집 오류·지연 제목: 설정의 수집 진단을 연다.

지표·모델명·카드·토큰 구성·미적중 안내는 표시 전용이다. 밑줄과 손 모양 커서는 대표 제목에만 표시한다. 최근 그래프는 클릭한 호출의 선과 네 숫자를 함께 고정한다. 같은 호출을 다시 클릭하면 해제하고 다른 호출을 클릭하면 고정을 옮긴다. 고정 중에는 마우스 이동으로 값이나 열린 상세가 바뀌지 않는다. 고정이 없으면 호버 값을 표시하고 벗어나면 최신 값을 표시한다. 최신 호출을 고정해도 새 호출을 따라가지 않으며 최근 12개 범위를 벗어나면 자동 해제한다. 탭·세션 전환도 고정을 해제한다. 방향키·Home·End는 고정을 이동하고 Enter·Space는 고정을 전환한다. 대시보드에서 직접 연 과거 상세는 별도로 보존한다. 그래프 클릭은 상세를 자동으로 열지 않는다.
속도 저하와 이벤트 근거는 상세의 읽기 전용 세션 근거에 포함한다. 계산 설명은 하단 계산 기준에 표시 내용에 해당하는 설명만 중복 없이 모으며 팝업은 사용하지 않는다. 미적중 필터는 세션 기록 화면에서 선택한다.
클릭 시 호출과 소유 세션을 보존하며 기록 갱신으로 다른 호출을 열지 않는다. 세션이 바뀌면 이동을 취소한다.

## 호출 선택과 데이터 범위

모델·추론 강도·요청 모드·연결 방식·최근 캐시율·최근 비용은 동일한 최신 호출을 사용한다.
요청 모드가 미확인일 때 응답 등급을 요청 모드로 대입하지 않는다. 응답 모델도 미관측이면 미확인이다.
캐시율의 분모는 확인 가능한 입력이며, 부분 표본은 `확인분`으로 표시한다.
비용이 없는 호출을0으로 처리하지 않으며 평균의 분모는 산정 가능한 호출 수다.
가격표와 미적중·저하 의심 판정은 기존 구현을 사용하고 새 임계값을 만들지 않는다.

기본 그래프는 부모와 하위 세션의 최근 12호출을 기록 시각순으로 병합한다. 전체 이력은 전송하지 않는다.
비용, 캐시율, 출력 속도, 추론 토큰의 네 그래프는 같은 호출 순서를 공유한다. 각 행은52px이며 평균이나 평균선은 추가하지 않는다. 오른쪽 숫자는 최신 호출 값이며 최신 값이 없으면 이전 값으로 대신하지 않는다. 각 축은 표시 값에 맞춰 자동 조정한다.
축 숫자는 상시 표시하지 않는다. 호버 또는 키보드 포커스 시 해당 호출의 값을 그래프 오른쪽 숫자에 표시한다. 툴팁은 사용하지 않는다.
미확인과 충돌은 선을 끊고 실제0은 표시한다. 표시된 실제 호출 수에 맞춰 X좌표를 나누며 빈 열에 가상 호출을 넣지 않는다. 속도는 비교 조건이 다르면 선을 연결하지 않는다.
상세 패널에는 중복 그래프를 표시하지 않으며, 호출의 소유 세션을 보존한 근거를 보여준다.

상세의 선택 호출과 세션 근거 영역을 스크롤한다.
스크롤바는 콘텐츠 오른쪽6px 밖에 배치한다. 고정 중에는 그래프 호버가 표시 호출을 바꾸지 않는다.
저하 의심 근거는 기존 판정이 제공한 비교 모델·모드·캐시 정책, 기준 평균 읽기·적중률·호출 순서와 실제 저하 호출의 관측값을 표시한다.
회복 시점이 제공되면 함께 표시하며, 그래프의24호출 범위를 벗어난 근거도 실제 기록에서 보존한다.
그래프 고정은 호출 ID로 보존하며 고정이 없으면 최신 호출을 따라간다.
대시보드에서 직접 연 과거 호출은 최근 그래프 범위를 벗어나도 읽던 근거를 유지한다. 실제 이력이 비거나 세션이 전환되면 제거한다.
기록 확인 중은 수치·그래프를 비우고, 수집 지연은 같은 세션의 확인값과 마지막 확인 시점을 구별한다.
원격·식별 불가 세션에 다른 로컬 세션을 대입하지 않는다.
수집 오류는 확인된 기록 손상·접근 실패·읽기 실패 등의 짧은 상태로 표시한다. 같은 상태는 건수로 모으고 원본 오류·경로·추적 정보는 오버레이에 노출하지 않는다.

## 입력과 테마

최상단 세션 제목은 드래그로만 이동한다. 헤더 아이콘은 상세·투명도·최소화, 복원 아이콘은 클릭 복원과 드래그 이동을 담당한다. 상세 우상단 × 또는 Esc로 닫으면 헤더 상세 버튼에 포커스를 돌려준다.
최소화·복원 선택은 Codex 홈과 세션별로 저장하며 세션 전환과 앱 재시작 후에도 유지한다. 새 세션은 표시 상태로 시작하고 위치·상세·투명도 설정은 공통으로 사용한다.
오버레이 전체에 호버 툴팁을 띄우지 않으며 접근성 이름과 키보드 포커스 표시를 유지한다. 생략된 제목과 모델명은 클릭한 상세에서 전체를 확인한다.
투명도 팝오버160×40에는 슬라이더와 백분율만 두며 외부 클릭·Esc로 닫는다.
Esc는 투명도 팝오버, 상세 순서로 닫는다. 최근 그래프에서 방향키·Home·End로 호출을 선택한다.
Tab·Shift+Tab으로 대표 제목·창 조작 버튼·호출 선택·상세 스크롤 사이를 이동한다. 제목과 복원 아이콘은 포커스가 있을 때 방향키로 이동하고 Shift를 함께 누르면10px씩 이동한다.
근거 스크롤은 위·아래·Page Up·Page Down·Home·End를 지원하며, 팝오버를 닫으면 투명도 버튼으로 포커스가 돌아간다.
모니터 본문은 링크 영역만 클릭을 받으며 나머지는 입력을 통과시킨다. 링크 위의 휠도 대상 창에 전달한다. 상세 영역은 선택·스크롤 입력을 받는다.
일반 표시·갱신·호버는 포커스를 가져오지 않으며 명시적인 컨트롤 조작 때만 키보드 입력을 받는다.
Codex 최소화·다른 앱 전환 시 모든 외부 창을 숨긴다.

Codex 배경·글자·강조색과 UI 글꼴을 읽고 유효한 지정 글꼴이 없으면 Pretendard JP를 사용한다.
사용자 배경 불투명도가 우선이며 기본값은94%다. 투명도 변경은 배경에만 적용한다.
범주색·주의·오류는 Codex 선택 강조색과 분리하고 기본 텍스트 대비를 유지한다.
상세는 크기·투명도 애니메이션 없이 최종 크기로 즉시 전환하며 오른쪽 모니터를 늘이지 않는다.
최소화·복원은100ms 전환, 조건부 높이 변화는120ms 전환을 사용한다. 복원 아이콘의32px 표면과 앵커는 외곽 포커스 링과 독립적으로 유지한다.
수치는 즉시 갱신하고 유휴 반복 애니메이션은 사용하지 않는다.

## 출력 속도 저하 안내

지속적인 속도 저하는 모니터에 읽기 전용으로 안내한다. 헤더 상세 버튼으로 상세를 열면 최근 평균·평소 기준·감소율과 세션 재생성 권장을 표시한다.
재생성이 속도 회복을 보장한다고 표현하지 않는다. 정상·표본 부족·관측 불가·수집 지연 상태에서는 아이콘을 표시하지 않는다.
최소화 상태에서는 복원 아이콘에 작은 주의색 점을 표시한다. 반복 점멸이나 포커스 강제 이동은 하지 않는다.

`speed_health.py`는 출력·추론 포함 토큰 합계 / 완료 호출 소요시간 합계로 비교한다.
같은 Codex home·모델·추론 강도·요청 등급·응답 ID로 확인된 통신 방식끼리 비교하며,
입력 구간은 공통 분석 구간, 출력 구간은 128–511 / 512–2047 / 2048–8191 / 8192 이상,
캐시율 구간은 75% 미만 / 이상을 사용한다. 128토큰 미만, 실패·취소·누락·충돌은 판단에 사용하지 않는다.
기준은 해당 호출보다 앞선 7일 이내 정상 표본 중 최대 30개, 최소 8개다.
현재 세션 표본을 우선하고 부족하면 같은 조건의 다른 세션 표본을 사용한다. 하위 세션 합계를 섞지 않는다.
기준 평균의 50% 이하이면서 기준 중앙값에서 3×1.4826×MAD 이하인 호출이 3회 이어지면 안내한다.
첫 저하 후보부터 기준을 고정하고, 기준 평균의 80% 이상으로 2회 회복하면 해제한다.
관측 불가·비교 조건 변경·7일 초과 간격은 연속 판단을 끊는다. 이는 속도 관측 기준이며 세션 원인 확정 기준이 아니다.

`python tools/demo_speed_overlay.py`는 운영 설정·기록·프록시와 분리된 더미 오버레이를 연다.
더미 창에서 정상·저하·회복을 전환하고 창을 닫으면 모든 더미 창도 함께 종료된다.

## 구현 위치와 검증

- `overlay_data.py`: 실제 호출 요약, 최근12호출, 세션 구성·판정 근거.
- `overlay_view.py`: 고정 배치·그래프·상세 선택과 표시.
- `overlay.py`, `overlay_tracking.py`, `overlay_windows.py`: 창·앵커·DPI·입력 통과·포커스.
- `overlay_chrome.py`, `qml/OverlayControls.qml`, `qml/OverlayDetail.qml`: 조작부·팝오버·상세 스크롤.
- `overlay_appearance.py`: 읽기 전용 Codex 모양 설정.

회귀 검사는 `tests/test_overlay*.py`에 있다. 실제 Windows 검사는 시험 프로세스 소유 창만 이동·최소화하며 실행 중인 Codex 창을 조작하지 않는다.
원본 기록 대조·렌더링·Windows 입력 검증과 설치된 실행 파일 검증은 서로 구별한다.
별도 한도 원장의 저장 오류가 실제 호출 수집을 중단시키지 않는다. 원장 오류는 진단 정보로 남기며 원장이나 원본 관측을 자동 삭제·복구하지 않는다.

사용량 원본 수집은 별도의 `--usage-collector` 백그라운드 프로세스 하나가 수행한다.
GUI 분석 프로세스와 캐시 작업기는 `usage_collection.py`의 소비자로서 같은 수집 결과만 읽는다.
GUI를 닫아도 전담 수집기는 유지되며, 장애 복구는 작업 스케줄러와 소비자의 전담 프로세스 재시작 요청으로 처리한다.
GUI나 캐시 작업기가 원본 수집을 승계하지 않는다. 파일 잠금은 전담 수집기 중복 실행만 막는다.
여러 Codex 홈의 구독은 전담 수집기에 합쳐 전달하고, 각 소비자에게는 요청한 홈의 결과만 반환한다.
공유 결과가 30초 이상 갱신되지 않으면 확인값을 보존하면서 지연을 표시한다.
원본 색인을 읽는 주체도 전담 수집기로 한정한다. 이전 직접 수집기와 작업기 색인 호환 경로는 유지하지 않는다.
